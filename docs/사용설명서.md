# SM(선명) 지방세·부동산·지자체뉴스 플랫폼 — 사용설명서

기준일: 2026-10-24 (MVP) · 대상: PO·편집국·관리자

이 설명서는 지금 만들어진 MVP를 써 보는 방법을 적은 것입니다. 기능은 대부분 꺼진 상태로 시작하고, 관리 화면에서 하나씩 켭니다.

---

## 1. 주소 두 개

| 구분 | 주소 | 쓰는 DB | 로그인 계정 | 언제 쓰나 |
| --- | --- | --- | --- | --- |
| **테스트 주소** | 손님 화면 https://sm-localtax-202610.vercel.app <br> 관리 화면 https://sm-localtax-202610.vercel.app/admin | 운영 DB (실제 자료가 쌓입니다) | **admin@sunmyung.kr** (비밀번호는 PO 비밀보관 폴더 파일) | 실제로 기사를 쓰고 기능을 켜 보며 MVP를 쓸 때 |
| **개발용 주소** | 손님 화면 http://localhost:3001 <br> 관리 화면 http://localhost:3001/admin | 이 PC 안의 시험용 DB (비어 있음) | **po@local.test** (비밀번호는 `data-src/local-admin.txt`) | 이 PC에서만 마음껏 눌러 보고 지워도 될 때. 테스트 주소에 영향이 없습니다 |

- 테스트 주소는 누구나 열 수 있지만 검색엔진에는 나오지 않게 막아 두었습니다.
- 개발용 주소는 이 PC에서 사이트를 띄웠을 때만 열립니다 (2장).
- 두 주소의 자료는 서로 섞이지 않습니다.

## 2. 시작하기

### 2.1 테스트 주소

1. 브라우저에서 https://sm-localtax-202610.vercel.app/admin 을 엽니다.
2. admin@sunmyung.kr로 로그인합니다.
3. 왼쪽 메뉴에서 일을 고릅니다 (3장).

### 2.2 개발용 주소 (이 PC)

- **띄우기**: Claude에게 "로컬로 띄워줘"라고 말합니다. 직접 하려면 VS Code 터미널에서 `pnpm dev:local`을 입력합니다.
  - Docker Desktop이 켜져 있어야 합니다. 시험용 DB가 꺼져 있으면 실행기가 먼저 켭니다.
  - 처음 한 번은 시험용 관리자 계정이 만들어지고, 로그인 정보가 `data-src/local-admin.txt`에 적힙니다 (저장소에 올라가지 않는 파일).
- **열기**: http://localhost:3001 (손님 화면), http://localhost:3001/admin (관리 화면)
- **끄기**: Claude에게 "꺼줘"라고 말하거나, 실행한 터미널에서 Ctrl+C를 누릅니다.
- AI 도우미 키는 `apps/web/.env.local`에 넣어 둔 값을 씁니다.

## 3. 관리 화면 메뉴

메뉴는 로그인한 계정의 역할에 따라 보이는 것만 나옵니다. 관리자는 모두 보입니다.

| 메뉴 | 하는 일 |
| --- | --- |
| 첫 화면 | 오늘 할 일과 대기 중인 검수 |
| 기사 기획 · 기사 | 기사 기획 → 작성 → 승인 → 발행. **쓴 사람과 승인하는 사람은 달라야 합니다** |
| 기사 배치 · 홈 배치 | 분야 화면과 홈에 어떤 기사를 어디에 둘지 정합니다 |
| 개정 트래커 | 지방세 개정안의 단계(입법예고·국회·공포 등)를 기록합니다 |
| 바깥 연결 | SM 계산기 같은 외부 사이트 주소를 관리합니다 |
| 허브 지방세 포인트 | 분야 허브 맨 위 '지방세 포인트' 문구 (세무 감수 뒤 공개) |
| 원문 검수 | 공식 자료 원문이 바뀌었거나 기한이 지난 것을 확인합니다 |
| 지역 기사 판정 | 지역 기사가 편집 기준에 맞는지 판정합니다 |
| 프로젝트 · 단계 지방세로 읽기 감수 | 정비사업 등 프로젝트와 단계별 고시 원문, 단계별 세금 해설 감수 |
| 분양 정보 | 분양 공고 (가격 칸 없음, 공식 공고 링크만) |
| 개발방법 비교 | 재건축·재개발 등 7개 방법의 비교표 (7개 모두 서명돼야 공개) |
| 개발금융 | 구조 해설·사례(실명 기업은 반론 기록 필수)·통계·규제 트래커 |
| 지자체뉴스 | 금주 핫뉴스(후보 → 선정 → 요약 → 발행)와 행사 목록 |
| 분야 · 사전 · 검색어 | 하위 분야, 용어 사전, 추천 검색어 |
| 제휴사 · 브랜드 관리 | 광고·제휴 표시, 브랜드 문구 |
| 스토어·구독 | 상품(도서·교육·구독 신청) 등록·판매 상태·기사/홈 '자사 상품' 카드 연결(제안은 상품 담당, 승인은 편집 책임자), 바깥 주문 허용 도메인·구독 확인 기록(관리자), 하위 화면 '수익 대시보드'(상품·출처 기사별 클릭 수). 결제는 없습니다. 공개하려면 설정에서 `store` 키를 켭니다 |
| 전문가 등재 | SM 소속 전문가 프로필 등록·공개·내리기, 연락 요청 확인 |
| 측정 지표 | 방문·재방문·지역별 성과 (편집비 입력 포함) |
| 제휴 준비 | 네이버 뉴스 제휴 준비 상태, 월별 지표·3개월 조합·경고 알림, 부정평가 기록, 규정 판단 값, 다음 접수 목표(설정) |
| 검색 최적화 | 색인 전환 점검(크롤러 정책·SITE_INDEXING), 법령 개정 신선도 검수, 핵심 질문 50개와 AI 검색 인용 표본 |
| 문의함 · 정책 페이지 | 고객 문의, 약관·처리방침 등 정책 문서 게시 |
| 설정 | 운영 설정과 **기능 키**(화면 스위치) |
| 회원·역할 | 회원 목록과 편집국 역할(기자·편집자·감수위원 등) 주기 |

## 4. 기능 켜기 (설정 → `feature_flags`)

조건이 갖춰지지 않은 기능은 켜려고 해도 화면이 이유를 알려 주고 저장되지 않습니다.

| 기능 키 | 켜면 보이는 것 | 켜는 조건 |
| --- | --- | --- |
| `region_hubs` | `/local` 지역 허브 | 없음 |
| `weekly_digest` | 금주 핫뉴스 | 설정 `digest_sidos`(서울·부산)·`digest_sources` 입력 |
| `local_events` | 행사안내·달력 | 없음 |
| `finance` | 개발금융 새 화면 | 법률 검토 기록 |
| `dev_methods` | 개발방법 비교 | 7개 방법 모두 서명 |
| `inheritance_gift` | 상속·증여 안내 | 세무 감수된 입문 기사 1건 + 고지 문구 |
| `experts` | SM 전문가 소개 | 전문가 고지문 승인 |
| `expert_requests` | 전문가 연락 요청 | `experts` + 연락 안내 문구 승인 |

핫뉴스 설정에 붙여 넣을 값은 `docs/dev/MVP_사용_시작.md` 2장에 있습니다.

## 5. AI 도우미

- 화면 오른쪽 아래 버튼을 누르면 열립니다.
- 사이트에 발행된 기사와 검색 결과만 근거로, 출처를 붙여 답합니다. 근거가 없으면 답하지 않고 관련 화면으로 안내합니다.
- 지금은 관리자·내부 계정에게만 보입니다. 일반 방문자에게 열려면 100문항 평가와 고지 문구 감수가 필요합니다.
- **테스트 주소**에서 쓰려면 Vercel 환경변수 6개가 있어야 합니다 (`docs/dev/MVP_사용_시작.md` 1장). **개발용 주소**에서는 바로 쓸 수 있습니다.

## 6. 자주 막히는 곳

| 증상 | 확인할 것 |
| --- | --- |
| 기사를 발행할 수 없다 | 쓴 사람과 승인하는 사람이 같은지, 화면의 점검 패널에 막힌 항목(근거·출처·고지 등)이 있는지 |
| 켠 기능이 손님 화면에 안 보인다 | 기능 키가 켜졌는지, 보여 줄 내용(공개된 기사·프로필)이 있는지. 빈 칸은 일부러 숨깁니다 |
| 개발용 주소가 안 열린다 | Docker Desktop이 켜져 있는지, Claude에게 "로컬로 띄워줘" |
| 개발용 주소 비밀번호를 잊었다 | `data-src/local-admin.txt`를 엽니다 |
| AI 도우미 버튼이 안 보인다 | 관리자로 로그인했는지, (테스트 주소라면) Vercel 환경변수와 다시 배포를 했는지 |
