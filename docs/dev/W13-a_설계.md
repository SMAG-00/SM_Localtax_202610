# W13-a 지식창고(LIB-01~07, AIOPS-16): 구현 설계 (개발 문서)

5단계 설계(`docs/dev/5단계_설계.md`) 1장 W13-a 행, 1.1 단계 a1~a9, 2.1 번호 191~196, 3장 a행, 4.1 누출 경로 표, 5장 #4~#9·#29·#30, PRD-05 LIB-01~07·AIOPS-16에 맞춘 구현 설계입니다. 설계와 다르면 5단계 설계가 맞고 이 문서를 고칩니다. (2026-10-27 작성)

지키는 선: 시험용 출판물 원고·칼럼은 모두 `시험용` 표시와 지어낸 글입니다. 가격·미리보기 길이·속도 제한 한도·고지 문구는 빈 칸(설정 입력)이고 시험에서만 값을 넣습니다. 이관(O7)은 유료 OCR 없이 가짜 입력(텍스트 조각)으로 검수·승인 흐름만 만듭니다. 기능 키 `library`·`library_premium`은 이 단위에서 켜지 않습니다. 이 단위의 서버 코드(`apps/web/lib/server/library`)는 AI를 호출하지 않고 `@ltr/igt-engine`을 불러오지 않습니다(NT9).

## 1. 확정한 결정

| 항목 | 결정 | 근거 |
|---|---|---|
| 프리미엄 칼럼 본문 표(5장 #7) | `paid_bodies` kind에 `column`을 더하는 쪽으로 합니다(194). 절단 로직은 `library_read` 하나를 쓰고, 칼럼은 `kind=column`일 때 `paid_bodies`를 읽습니다. 지식창고 노드·권호 기사 본문은 `library_bodies`(191)에 둡니다 | 기사 본문 표와 같은 직접 권한 0 방식, 새 판매 표 0 |
| 필자 표 | 설계의 `authors`는 1단계 `people`입니다(별도 표 없음). 계약 칸(`contract_status`·`contract_until`, 금액 칸 0)은 `people`에 더합니다(194) | `articles.author_id`가 이미 `people`을 가리킴 |
| 권한 키 | 열람 권한은 `has_entitlement(user, 'library')` 하나입니다. 비구독자·키 없음·만료는 미리보기만 | 190 확정 결정 |
| 미리보기 | 본문에 미리보기 칸을 따로 두지 않고 서버 함수가 본문에서 `library_preview` 설정 길이만큼 잘라 냅니다(설정이 비면 0자). 검색 요약·메타 설명·RSS·구조화 데이터는 이 잘린 값만 입력으로 씁니다 | 누출 표면 최소화(저장된 미리보기 칸이 본문과 어긋날 일 0) |
| 공개 조건 | 노드·권호·기사가 `status=approved` ∧ `rights_public=confirmed`이고 기능 키가 켜져 있을 때만 공개 뷰에 나옵니다. 유료 판매 권리(`rights_sale`)가 없으면 프리미엄 본문은 구독자에게도 열리지 않습니다 | LIB-06 |
| 승인 | 노드·권호·기사의 `approved`는 이관 작업(192)의 승인 함수로만 됩니다(`approved_job_id` 필수 제약). 직접 승인 0 | AIOPS-16 |
| 권리 변경 기록 | 트리거가 `library_rights_log`(추가만)에 자동으로 남깁니다. 행위자는 세션 값 `ltr.actor` | LIB-06 감사 |

## 3. 서버·화면 단계

### 4.2 설정 값 모양(PO 입력)

- `library_preview`: `{"chars": N, "max_ratio_percent": P}` (두 번째는 선택). 비면 미리보기 0자. 본문 길이 이상이면 0자.
- `library_rate_limit`: `{"max": n, "window_seconds": s, "bulk_copy_max": m, "bulk_copy_window_seconds": w}` (뒤 둘은 선택). 앞 둘이 비면 열람이 닫힙니다.
- `digitization_sample_error_max`: `{"percent": 0.5}` (190 씨앗). 비면 승인이 닫힙니다.

### 4.3 PO 입력 목록

T1 출판물 권리표(용도별 4칸+PDF), 이관 원고, 필자 계약(상태·종료일), `library_preview` 값, `library_rate_limit` 값, 프리미엄 요금제 가격(시험 가격만 사용), 지식창고 색인 세목 분류(`taxItems`, 현재 임시값 `지식창고` [확인 필요]), 유료 OCR 도구(미사용 — 가짜 입력으로 흐름만).
