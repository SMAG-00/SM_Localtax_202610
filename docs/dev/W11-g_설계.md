# W11-g 상속·증여세 자체 계산 (안심 상속증여계산기 엔진 이식) 설계 (개발 문서)

기준: `docs/dev/3단계_설계.md` 0.4·1·1.1·2.1·2.2·3·4.3·4.4·5(#21~24)·6·7, PRD-03 4-K(FAM-10~15), PRD_최종 §2.2 원칙 ④(2026-10-25 개정 — W11-g). 작성일 2026-10-26.
이 문서는 만들 항목을 빠짐없이 적고, 항목마다 단계와 시험을 묶습니다. 값(세율·공제·한도)은 이 문서에 적지 않습니다.

## 1. 원칙

1. 허용 구역은 `scripts/national-tax-zones.json` 한 곳입니다. 상속·증여 코드는 `packages/igt-engine/**`, `rules-igt/**`, `apps/web/app/(site)/calc/{gift-tax,inheritance-tax}/**`, `apps/web/components/site/igt/**`, `apps/web/lib/igt/**`, `packages/db/supabase/migrations/*_w11g_*.sql`, `packages/db/tests/w11g-*`, `e2e/w11g-*`에만 둡니다. 구역 안에서도 다른 세목 묶음의 낱말(NT7)은 쓰지 않으므로, 금지 낱말을 검사하는 코드는 낱말을 조각으로 이어 적습니다.
2. 계산은 브라우저에서만 합니다. 서버 계산 API, 입력값 저장·전송·URL·분석 이벤트·브라우저 저장소는 0입니다. 서버는 서명된 활성 룰셋과 게이트 판정만 내려보냅니다.
3. 게이트는 DB 뷰(`calc_gate_status`의 `gift ALL`·`inheritance ALL`) + 배포된 엔진 해시입니다. 수동으로 여는 길이 없고, 증여와 상속은 따로 열립니다. 닫히면 두 경로는 404이고 외부 계산기 카드(FAM-08)가 남습니다.
4. 국세 금액은 지방세 금액과 한 줄로 합치지 않습니다. AI는 국세 금액을 만들지 않습니다(`assistant`·`agent`·`workflows`는 `@ltr/igt-engine`을 import하지 않음 — NT9). `@ltr/tax-engine`과 `@ltr/igt-engine`을 함께 import하는 파일은 참조 목록 밖에 없습니다(NT8).
5. 안심 원본 폴더는 읽기만 합니다. 사본(`packages/igt-engine/reference/`)에서만 `python -I -B`로 실행합니다. `.env*`, `web/.env.local`, `web/.vercel/`은 열지 않습니다.
6. 룰셋 값은 안심이 AI로 시행령과 대조한 미감수 값입니다. `draft`로만 두고, PO 서명 + 보조 교차 확인 전에는 공개 계산에 쓰지 않습니다. 기능 키 `calc_igt_gift`·`calc_igt_inheritance`는 꺼짐으로 시작합니다.

## 3. 단계

- **g1 출처 고정**: `calc_igt.py`, 시험 `test_calc_igt.py`(57), 예시 4개, 룰셋 사본을 `reference/`에 복사하고 `SOURCE.json`에 파일별 SHA-256·룰셋 version(`2026.07.12-v1`)·복사일(2026-10-26)·복사하지 않은 목록·코드 상수 목록을 기록합니다. 사본의 줄바꿈은 LF로 정규화되어 룰셋 사본만 해시가 원본과 다르므로 `sourceSha256`을 함께 둡니다. 복사하지 않는 것: `simulate_igt.py`, 부담부증여, 다른 세목 계산 파일과 룰셋, `filing_draft.py`, `explain_report.py`, `analyze_impact.py`, `approve.py`, `web/api/*`.
- **g2 기준선**: `baseline/make_baseline.py`를 `python -I -B`로 사본에서 실행합니다. 원본 시험 57개가 부르는 입력·출력(55호출+보조 함수), 예시 4개, 시드 20261026 무작위 입력(증여·상속 각 300)을 `baseline.json`에 고정합니다. 기준선은 안심 현행 동작이며 법령 정답이 아닙니다.
- **g3 TS 이식**: `@ltr/igt-engine`. 내보내는 값은 `calcGift`·`calcInheritance` 둘뿐(납부 안내 데이터는 결과의 `payment`). 네트워크·AI·환경변수·파일·시계 접근 0. 정수 안전 범위 초과 거부와 `-0` 제거는 의도된 차이로 `SOURCE.json`에 적습니다.
- **g4 `rules-igt/`**: `2026.07.json`(draft, 서명 기록 없음, 원본의 AI 승인 기록은 옮기지 않음) + `versions.lock.json` + `bundle.json`(비어 있음). 기존 `check-rules`의 추가 폴더 규칙으로 R1~R4를 검사합니다. 원본 `needs_verification`이 모두 `false`여서 감수 목록 칸은 비었고, 대신 미반영 개정과 코드 상수 목록을 감수 입력으로 남깁니다.
- **g5 마이그레이션 136~138**: 136 `igt_rulesets`(+가드 트리거·서명/승인 함수·`rules_audit` 종류·공개 뷰·기능 키), 137 대조 사례 세목·실행 기록·게이트 묶음, 138 `laws` 범위와 이름·첫 검수 항목. 139~140은 예비입니다.
- **g6 화면**: 두 경로는 서버에서 기능 키·게이트·활성 룰셋을 확인하고 하나라도 아니면 404입니다. 계산 컴포넌트는 클라이언트이며 폼 상태(메모리)만 씁니다. 결과에는 `국세` 배지, 룰셋 버전·엔진 해시 각인, 고정 문구, 확인 필요 고지를 보입니다.
- **g7 `toolLinkFor`**: 세목별 새 도구(`gift_tax`·`inheritance_tax`)를 더해 기능 키 + 게이트 + 해시가 맞을 때만 자체 카드, 아니면 외부 카드를 돌려줍니다. 합친 카드(`inheritance_gift`)는 변하지 않습니다. 카드를 그리는 호출부를 세목별 도구로 바꾸는 일은 마지막 연결 단계입니다.
- **g8 법령 감시**: `laws`에 상속세 및 증여세법 3행(scope `national_igt`). 실행은 기존 W10-c 파이프라인이며 원천 이용 조건이 확인되기 전에는 요청 0입니다. 안심이 2026-10-08에 감지한 미반영 개정 3건을 첫 검수 항목(제목·출처 표시만)으로 등록합니다.
- **g9 수용**: `e2e/w11g-acceptance.test.mjs`(작성만, 실행은 리드).

## 4. 결정 기록 (2026-10-26)

1. **코드 상수 → 룰셋**: 안심 원본이 코드에 박아 둔 숫자 15개(동일인 합산 하한, 과세표준 부과 하한, 세대생략 강화 기준 증여재산, 금융재산 전액공제 기준, 연부연납 회분 하한, 물납 세액 기준, 과세가액 기준, 미성년 연령 상한, 신고기한 개월 3종, 연부연납 최대 연수 2종, 물납 재산 비율, 배우자 상속분 가산)를 `rules-igt/2026.07.json`의 `common.thresholds`로 옮겼습니다(값은 원본 코드 그대로, `needs_verification: true`로 감수 목록에 올림). 엔진은 이 칸이 없으면 계산하지 않으며, 엔진 소스에는 세액 판단용 숫자 리터럴이 없습니다(시험이 검사). 사본 룰셋에는 이 칸이 없으므로 동일 출력 시험은 사본 룰셋에 초안의 `thresholds`만 붙여 돌립니다. 설명 글에 박힌 금액 글자는 계산이 아닙니다.
2. **`FORBIDDEN_IDENTIFIERS`**: PO가 CI 비밀값에 직접 더합니다(이 단위에서는 더하지 않음).
3. **첫 검수 항목 제목**은 안심 `changes/20261008` 파일 이름에서 정했습니다 [확인 필요].
4. **허용 구역 밖 파일**: `calc-tools.ts`, `next.config.ts`, `apps/web/package.json`은 이름만 언급하는 참조 파일로 `scripts/national-tax-zones.json`에 올렸습니다. 허브 카드(`CalcHub.tsx`)와 `calc/page.tsx`, `jobs.ts`는 중립 이름(`OwnCards`, `runNationalAccuracy`)만 쓰고 상속·증여 코드는 구역 안(`components/site/igt/OwnCards.tsx`, `lib/igt/*`)에 있습니다.

## 5. 이번에 만든 것과 남은 것

만든 것: 엔진·기준선·초안 룰셋·마이그레이션 136~138·두 계산 화면·`toolLinkFor` 세목별 전환·`/calc` 허브 자체 카드(두 세목이 모두 열릴 때만 외부 카드가 빠짐)·대조 실행 계산(`lib/igt/accuracy.ts`, `run.ts`, 배치 `accuracy-run`에서 지방세 실행 뒤에 이어서 실행)·DB 시험·수용 E2E.

남은 것(해결됨 2026-10-26): 관리 화면은 `apps/web/app/admin/**`·`apps/web/app/api/admin/**`라서 허용 구역 밖입니다. 상속·증여 룰셋 서명·승인 버튼, 대조 사례 입력, 게이트 표를 보이려면 구역 목록에 관리 경로를 더해야 합니다(예: `apps/web/app/admin/(desk)/igt-*/**`, `apps/web/app/api/admin/igt-*/**`). 그 전에는 서명·승인은 DB 함수(`sign_igt_ruleset`, `approve_igt_ruleset`)를 서버 스크립트로 부르고, 사례는 SQL로 넣습니다. 기존 `/admin/accuracy` 표는 지방세 세목만 라벨이 있어 상속·증여 줄은 라벨 없이 보입니다.
그 밖에: 외부 카드 자리 중 `/calc` 허브만 자체 카드로 바꿨습니다. 상속·증여 안내 페이지(FAM-01·02·08)와 「지방세로 읽기」 옆 국세 카드는 같은 `ownCardState`/`toolLinkFor`로 바꾸는 연결이 남았습니다. 수집 파이프라인에서 `national_igt` 법령을 실제로 도는지(`unchecked`이면 요청 0)는 W10-c 파이프라인 시험으로 확인해야 합니다.

## 6. 관리 화면과 카드 전환 (2026-10-26 추가)

- 허용 구역에 `apps/web/app/admin/(desk)/igt/**`, `apps/web/app/api/admin/igt/**`, `apps/web/components/admin/igt/**`를 더했습니다(`scripts/national-tax-zones.json`, `docs/dev/3단계_설계.md` 4.4). 관리 메뉴 파일(`lib/admin/menu.ts`)은 이름만 언급하는 참조 파일입니다.
- `/admin/igt`(메뉴 이름 "국세 계산 감수", id `national-calc`): 공개 게이트 표(세목마다 공식 결과·표본 건수, 엔진 해시 일치, 부족한 것), 룰셋 버전 표(서명·승인 버튼), 초안 만들기, 대조 사례(확인·철회·추가), 서명·승인 기록. 권한은 기존 `ruleset.read`/`ruleset.sign`/`ruleset.approve`/`accuracy.manage`를 그대로 씁니다.
- `/api/admin/igt`: `create`(관리자) · `sign`(세무 감수위원만, 관리자는 403 + 거부 감사) · `approve`(관리자만) · `case_add` · `case_confirm`(감수위원만) · `case_retire` · `run`. 서명·승인은 DB 함수만 부르고 열고 닫는 입력은 없습니다. 감사에는 입력·금액을 싣지 않습니다.
- 외부 카드 자리 전환: `/calc` 허브, 상속·증여 안내 페이지(FAM-01·02·08), 「지방세로 읽기」 박스 옆 카드가 같은 판정(기능 키 + 공개 게이트 + 엔진 해시, `toolLinkFor`와 같은 조건)으로 자체 카드로 바뀝니다. 두 세목이 모두 열리면 합친 외부 카드가 빠지고, 하나만 열리면 외부 카드가 남습니다. 박스 옆 카드는 박스 세목에 나온 세목만 대상입니다.

## 7. 남기는 일(감수·외부)

1. PO 서명 + 보조 교차 확인(룰셋 draft → reviewed → active).
2. 공식 결과 대조 증여·상속 각 30건 이상 + 감수 표본 50건(`accuracy_cases`).
3. 미반영 개정 3건 검토, 엔진의 코드 상수(`SOURCE.json` codeConstants)를 룰셋 칸으로 옮길지 결정.
4. 안심 배포·OC 식별자는 `FORBIDDEN_IDENTIFIERS` CI 비밀값에 PO가 직접 더해야 합니다(목록 파일이 아닌 비밀값이며 값은 `.env`를 열어야 알 수 있어 이 단위에서는 더하지 않았습니다).
5. 안심 사이트 처리·운영 주체 표기(§13 #4) 결정 전에는 외부 카드 유지.
