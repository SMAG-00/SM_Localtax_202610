# W8 스토어 · 주문 경로 · 광고 정책 · 수익 대시보드 — 설계 약속 (개발 문서)

PRD-01C 8장 W8(BIZ-01·02·03·08·09, BR-11의 '자사 상품' 카드)을 구현할 때 DB·서버·화면·시험이 같은 이름과 같은 규칙을 쓰기 위한 약속입니다. W7c 설계와 같은 모양으로 짧게 씁니다.

**이 문서와 구현은 실제 상품·가격·판매처·정책 문구를 쓰지 않습니다.** 화면 틀·입력 방식·공개 조건·빈 내용일 때의 표시만 정합니다. 운영 DB의 씨앗은 설정 기본값(주문 허용 도메인 빈 목록·구독 감수 기록 미승인)뿐이고 상품·연결은 0행입니다. 상품 목록·판매처·광고 정책 문구는 PO가 직접 넣습니다. 시험 자료는 모두 지어낸 값(`*.example.test`, 가상 상품명)입니다.

**1단계에는 결제가 없습니다(결제는 2단계, BIZ-04~06).** 카드번호 입력·PG 스크립트·장바구니·가격 카운트다운·팝업은 만들지 않습니다. 주문 경로는 둘뿐입니다 — 바깥 판매처로 나가는 링크(`existing_channel`, 허용 도메인만) 또는 기존 문의함의 구독 문의 폼(`request_form`).

## 2. 데이터 모델

| 표 | 핵심 칸 | 규칙 |
|---|---|---|
| `products` | slug, title, kind(book·education·subscription), summary, audience, edition(판차)·toc(목차), order_mode(existing_channel·request_form), order_url, verified_on·verified_ref(실사 확인일·근거), status(draft·on_sale·stopped), edited_by | 판매 중은 확인일·근거가 있어야만. 도서는 판차·목차가 있어야 판매 중. `existing_channel`은 `https` 주소이고 호스트가 설정 `store_order_domains`에 있어야 하며, 목록에서 빠지면 그 상품은 공개에서도 빠짐. `request_form`은 주소 없음. 제목·요약·대상에 할인·가격 표기 거부(도서정가제 감수 전). 가격·결제·재고 칸 없음 |
| `product_links` | product_id, placement(article·home), article_id, status(proposed·approved·revoked), proposed_by, approved_by·approved_at | 상품 담당이 제안, 편집 책임자·관리자가 승인(API 권한 `product.approve`). 기사 하나에 승인 1개·홈 승인 1개(부분 유일 색인). 승인 기록 없는 카드 렌더 0 |
| `public_store_products` (뷰) | 공개 칸만 | 기능 키 `store` 켜짐 + 판매 중 + 확인일·근거 + 주문 도메인 허용 + (구독이면 `store_subscription_review` 승인). 상품 안내라 뉴스 목록·사이트맵 뉴스 후보·자체 취재 집계에 들어가지 않음(기사 표와 무관) |
| `public_product_links` (뷰) | 승인된 연결 + 공개 상품 칸 | 중지·키 꺼짐이면 다음 요청부터 0행 |

설정: `store_order_domains`(소문자 호스트 배열, 씨앗 `[]` — 비어 있으면 바깥 주문 링크 상품은 공개되지 않음) · `store_subscription_review`(`{approved, ref, reviewed_by, reviewed_on}`, 씨앗 미승인 — 승인 전 구독 종류 상품 공개 0, BIZ-01 '정기간행물 등록·구독료 부가세 확인 기록 전 구독 신청 화면 공개 0'). 기능 키 `store`는 기존 키이며 꺼짐이 기본입니다. 구독 감수 기록과 허용 도메인은 DB 트리거가 모양을 검사하고 공개 뷰가 조건을 다시 봅니다.

측정 이벤트(W2-c 표와 동기화): `product_clicked`(카드 누름 — `product_id`·`placement` article·home·store·`article_id` 선택)와 `order_link_clicked`(주문 링크/문의 누름 — `product_id`·`placement`·`mode` existing_channel·request_form·`article_id` 선택). 분야 칸은 선택. 가격·이름·주소 칸 없음.

## 11. 기록

- 상품 등록·수정·상태 변경, 연결 제안·승인·철회, 허용 도메인·구독 감수 기록 변경은 모두 감사 로그(`store.*`)에 남습니다. 승인 거부(권한 없음)도 감사 대상입니다.
- 수익 대시보드(`/admin/store/revenue`)는 기간(7·30·90일)별로 상품 × 위치(기사·홈·스토어) × 출처 기사의 카드 누름 수와 주문 링크 누름 수를 보여 줍니다. 봇·편집국 세션은 뺍니다. 측정 거부·GPC 방문자는 원래 저장되지 않으므로 실제 클릭보다 작게 나옵니다. **금액·공헌이익은 1단계에 없습니다** — 결제가 없고 비용 항목 정의(PRD 결정 안건)가 정해지지 않았습니다(2단계 BIZ-09 확장).
- 공개 요청마다 기능 키·판매 상태·허용 도메인을 뷰가 다시 판정하므로, 판매 중지·키 끄기는 배포 없이 다음 요청부터 반영됩니다.
