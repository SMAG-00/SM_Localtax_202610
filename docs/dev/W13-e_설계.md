# W13-e 리서치 코파일럿 (RES-01~05): 구현 기록 (개발 문서)

5단계 설계(`docs/dev/5단계_설계.md`) 1장 W13-e 행, 1.1 단계 e1~e6, 번호 210~212, PRD-05 RES-01~05에 맞춘 구현 기록입니다. 설계와 다르면 설계가 맞고 이 문서를 고칩니다.

지키는 선: 새 모델 호출 경로 0(4단계 `runAgentTurn` 한 곳만 부름), 검증기 V1~V6 그대로, 금액은 모델 글이 아니라 근거·계산 도구에서만, 국세 금액 0(NT1~NT9, `@ltr/igt-engine` import 0), 고지·약관 문구는 쓰지 않음(고정 문구는 4단계 `EMPTY_COPY` 빈 칸).

## 1. 기능 4종과 입력 경계

| 종류 | PRD | 입력 | 근거를 모으는 방법 |
|---|---|---|---|
| `comparison` | RES-01 | 결정례 `source_id` 2~8건(중복 제거 뒤). 1건·9건은 화면 버튼 비활성, 서버도 422 | 고른 건을 `getSource`로 읽습니다. 못 찾은 건이 있으면 422 |
| `history` | RES-02 | 조문 표기 + 기간(시작·끝, ISO 날짜) | 기간 안 기준일들로 조문 개정판을 모읍니다. 개정 일자는 DB 원문 값(칩)만 |
| `publications` | RES-03 | 조문 표기 | 출판물 청크 중 **요약 권리 확인·색인 권리 확인·승인** 건만(`copilot_summary_allowed`, 211). 0건이면 모델 호출 0 |
| `issue_memo` | RES-04 | 조문·결정례 `source_id` 1~8건 + 메모(2,000자 이하, 선택) | `comparison`과 같음. 결과는 사용자가 "내 메모로 저장"할 때 `AI 초안` 표지와 함께 메모 API로 저장 |

근거 도구 상자는 **미리 모은 문서 목록만** 돌려줍니다(`restrictedToolbox`). 모델이 검색으로 목록 밖(라운지 글·메모 포함)을 끌어올 길이 없습니다. 라운지·메모는 색인 허용 목록에도 없습니다(W12-a).

## 2. 공개 판정 (RES-05)

`decideCopilotGate`(순수): 기능 키 `research_copilot` ∧ 모델 환경변수(`AGENT_MODEL_COPILOT`) ∧ 공개 단계가 none이 아님(= 4단계 게이트 리포트 + 승인, W12-e) ∧ 월 한도 설정이 양의 정수 ∧ 계정 조건. 계정 조건은 4a·4b에서는 내부 계정(직원·초청 전문가 역할)만, 4c에서는 `copilot` 권한(`has_entitlement`)이 있는 회원입니다. 하나라도 거짓이면 API는 404이고 모델 호출 0입니다. 한도 소진은 429 + 안내 코드입니다.

월 한도: 설정 `copilot_monthly_limit`. 빈 값(`{}`)이면 실행 0. 인식하는 모양은 양의 정수 숫자 또는 `{ "per_user": n }`입니다. 코드에 한도·모델 ID 상수는 없습니다.

## 3. 마이그레이션 (210~212)

| 번호 | 내용 |
|---|---|
| 210 | `copilot_usage`(회원·달·횟수), `copilot_runs`(종류·상태·모델 표지·인용 `source_id`[]·검증 요약·토큰·비용). 질문·메모·답변·입력 구조체 칸 없음. 함수 `copilot_consume`(원자적 차감, 한도 n번째 허용 n+1번째 거부)·`copilot_refund`·`copilot_peek`·`copilot_record_run`은 service_role만 |
| 211 | `copilot_summary_allowed(text[])` - 요약 권리 필터(service_role) |
| 212 | 예비(사용하지 않음) |

표는 `revoke all`로 anon·authenticated·service_role 직접 접근을 모두 막고, 서버는 함수로만 읽고 씁니다(169 방식).

## 4. 흐름

요청 → 모델 설정·기능 키·단계(404) → 로그인·계정 조건(404/401) → 입력 검사(400/422) → 근거 수집(0건이면 422, 모델 0) → 월 한도 차감(429) → `runAgentTurn`(전문가 모드, 코파일럿 모델·강도) → SSE → 기록(`copilot_record_run`). 답변이 못 나온 실행(error·fallback·clarify)은 한도를 되돌립니다. 결과는 기존 스크랩 API(`copilot_result`, 대상 번호 = 실행 ID)와 메모 API로 워크스페이스에 저장하고, 내보내기(WS-05)는 W13-b가 이미 처리합니다.

## 5. 화면

`/workspace/copilot` (워크스페이스 안, 기능 키 꺼짐이면 404, 실행 버튼은 게이트가 열려야만 활성). 모든 결과에 "AI 초안" 표지를 답니다.

## 6. PO 입력 대기

- 4단계 게이트 리포트·공개 단계 승인(4b/4c) - 그 전에는 실행 0
- 설정 `copilot_monthly_limit` 값(유료 한도 결정)
- 환경변수 `AGENT_MODEL_COPILOT`·`AGENT_EFFORT_COPILOT`(계약·공시 확인 뒤)
- 코파일럿 안내·면책 문구(법률 검토 뒤, 현재 빈 칸)
- 이벤트 `copilot_used`는 화면(`CopilotPanel`)이 실행 성공 뒤 기존 클라이언트 분석 방식으로 발송합니다(feature 값만, 질문 원문 없음)
