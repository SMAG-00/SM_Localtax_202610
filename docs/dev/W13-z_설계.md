## 5. 알려진 한계

1. **`/api/feeds`는 키가 꺼져도 404가 아닙니다.** 제3자가 쓰는 키 인증 API라서 키 없음 401, 기능 키 꺼짐·한도 없음 503으로 닫히고(W13-i 설계 3절) 본문은 0입니다. `w13-acceptance` d는 이 닫힘을 허용합니다.
2. **R1은 측정만**: 새 공개 화면의 첫 화면 글자 수는 기록만 합니다(전부 150자 미만이지만 `/security`는 177자, W12-z 4장과 같은 PO 판단 안건). R2·R3·접근성·가로 스크롤은 강제합니다.
3. **라운지 '기준 변경 이력' 공개 표시**(W13-g 남은 과제)는 이력 원본이 관리자 감사 로그라 공개 화면에 두지 않습니다. 보여 주려면 공개 가능한 이력 표를 따로 만드는 작업이 필요합니다. 기본 결정: 이번 단계에서는 만들지 않습니다.
4. 분할 화면 경계(1279/1280/1023/1024px)와 p95 실측은 컴퓨트 확장 뒤 PO 입력입니다.
