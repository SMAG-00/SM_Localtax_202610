# W10-g 교육 강좌 안내·위탁교육 견적·세미나: 구현 기록 (개발 문서)

2단계 설계(`docs/dev/2단계_설계.md`) 1장 W10-g·3장·5장 #27·#28에 맞춘 구현 기록입니다. 설계와 다르면 설계가 맞고 이 문서를 고칩니다. PRD가 다르면 PRD가 맞습니다. (2026-10-25 작성)

지키는 선: 교육원은 **"연결"로 시작**합니다(결정 #27, 권고 기본값을 PO 위임으로 적용). 결제·수강 등록·수료증은 교육원 사이트가 맡고, 이 사이트는 강좌·세미나 안내와 위탁교육 견적 요청만 받습니다. 동의 문구·보관 기간 확정값·강좌 내용은 이 문서와 코드에 없고 빈 칸 또는 설정입니다. 시험 자료는 `시험용` 표시와 지어낸 값입니다. 기능 키(`edu`·`education_billing`·`seminars`)는 꺼 둔 채 출하합니다.

## 2. 구현 결정 (PO 위임, 권고 기본값 적용)

| # | 결정 | 이유 |
|---|---|---|
| 1 | 연결 방식: 결제·정원·수강 등록·수료증 표와 라우트를 만들지 않음. `course_enrollments`·`certificates`는 통합으로 바뀔 때 새 마이그레이션(99 이후)으로 추가 | 설계 #27 |
| 2 | 기능 키는 새로 만들지 않고 0차에 있는 `edu`(강좌), `education_billing`(견적 요청), `seminars`(세미나)를 씀. `education_billing` 이름은 결제를 뜻하지 않으며 이름 정리는 통합 여부가 정해질 때 | 공통 파일 변경 최소화(`FEATURE_KEYS`와 W2-b 설계 목록 불변) |
| 3 | `education_billing`·`seminars`는 `edu`가 함께 켜져야 하고, 견적 요청은 정책이 승인되어야 켜짐(DB 트리거 + 앱 의존 표) | 빈 링크 0, 법률 검토 전 개인정보 수집 0 |
| 4 | 견적 보관 기간 기본 365일(30~1825) `[법률 검토]`, 첫 회신 목표 3영업일, 문의 내용 상한 1000자. 모두 `training_quote_policy` 설정 값. 동의 문구·안내 문단은 비어 있고 법률 검토본만 넣음 | 보관 기간·동의 문구는 법률 항목 |

### 3.3 남은 일

- 관리 화면(`/admin/education`)과 관리 메뉴 항목은 만들지 않았습니다(메뉴 정확 비교 E2E와 함께 리드).
- `docs/dev/진행_현황.md`·PRD_최종 §11.0 W10 상태 칸은 병렬 작업 충돌을 피해 고치지 않았습니다.
- `/edu`는 1단계 EDU-01 화면이 이 저장소에 없어 이 단위가 처음 만들었습니다(기능 키 `edu` 꺼짐).

## 4. PO 확인이 필요한 항목 (모두 권고 기본값으로 진행함)

1. 견적 보관 기간 365일: 법률 검토 후 확정 `[법률 검토]`.
2. 견적 양식 동의 문구·안내 문단·법률 검토 기록 번호: 법률 검토본 입력 전 `education_billing`을 켤 수 없음.
3. 교육원 신청 주소: 관리 화면에서 `official_links`(kind `edu_site`)에 입력, 자동 점검 허용 여부.
4. 교육원 통합으로 바뀌면: `course_enrollments`·`certificates`·결제 연결을 새 마이그레이션으로 추가(환불 기준 `[감수 필요]`).
5. `education_billing` 키 이름 정리 여부(연결 분기에서는 결제 의미 없음).
