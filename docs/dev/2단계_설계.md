# 2단계(W10) 자체 계산기·해석 DB·디지털 구독: 작업 단위 설계 (개발 문서)

PRD-02(v2.0, 요구사항 88개 — 2026-10-25 바로가기·캠페인 랜딩 8개 포함)와 PRD_최종 §11.1 W10 행을 구현할 때 작업 단위·순서·마이그레이션 번호·데이터 이름을 맞추려고 정한 약속입니다. 이 문서와 PRD가 다르면 PRD가 맞고, 이 문서를 고칩니다. 1단계에서 정한 값 목록·공개 읽기·캐시·기능 키·감사 규칙은 그 단계의 설계 문서를 그대로 따릅니다. (2026-10-25 작성)

**지키는 선 (PO 결정 2026-10-25)**
- 이 문서와 구현에는 실제 법령·세무 문장, 세율·공제·기한·한도 값, 감면 요건, 달력 날짜를 쓰지 않습니다. AI는 구조와 시험 자료만 만듭니다. 시험 자료에는 모두 `시험용` 표시를 붙이고 지어낸 값을 씁니다. SM에서 복사한 룰셋 값은 "SM이 이미 가진 AI 작성·미감수 값"으로, 감수 서명 전에는 `draft`로만 둡니다.
- 새 기능은 모두 기능 키를 꺼 둔 채 출하합니다. 코드 완료와 공개 승인은 따로 둡니다(MVP 방식 — 테스트 주소에서 켜 보며 고침).
- 결제는 계약 전까지 시험(샌드박스) 모드만 씁니다. 실결제 경로는 계약·신고 기록이 없으면 열리지 않습니다.
- SM 부동산 세금 플랫폼은 바꾸지 않습니다. 코드는 읽고 복사만 합니다. SM 폴더에는 파일을 하나도 쓰지 않습니다(설치·시험 실행·캐시 생성 0).
- 국세(상속세·증여세·양도세) 금액은 이 단계에서 만들지 않습니다(원칙 ④, CI `check-national-tax`). 상속·증여세를 사이트 안으로 들이는 방안은 5.2.
- 분야 이름: 지방세·부동산세금(`/tax`) / 부동산재테크(`/realestate`) / 부동산금융(`/finance`) / 지자체뉴스(`/local`). 사이트 이름은 `packages/ui/src/brand.ts`에서만 읽습니다.

쓸 수 있는 자산: 「안심 상속증여계산기」(PO가 만든 사이트, 저장소 `C:\Users\juncp\00_claudecode\11_Inheritance and Gift Tax` — Python 엔진 `calc_igt.py`·룰셋·상증세법 감시·승인 도구·시험). SM 코드가 아니므로 "SM 불변"은 해당하지 않지만 같은 원칙(원본 수정 0, 복사·이식)을 권합니다. 부담부증여(양도세 엔진 의존)는 이식 범위에서 뺍니다.
