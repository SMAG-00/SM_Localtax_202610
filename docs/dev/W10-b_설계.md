# W10-b 계산기 화면·위택스·진입점 전환: 구현 설계와 기록 (개발 문서)

2단계 설계(`docs/dev/2단계_설계.md`) 1장 W10-b와 PRD-02 4.1·4.2·4.11·4.12에 맞춘 구현 문서입니다. 설계와 PRD가 다르면 PRD가 맞고 이 문서를 고칩니다. (2026-10-25 작성)

지키는 선: 이 단위의 코드와 시험 자료에는 실제 세율·공제·한도·기한·감면 요건·법령 문장·달력 날짜를 쓰지 않습니다. 시험 자료는 지어낸 값에 `시험용`을 붙입니다. 정책·법 문장이 필요한 자리(판정표 요건, "모르겠어요" 가정, 도움말, 감면 금액)는 빈 칸으로 두고 감수 입력을 받습니다. 국세(양도·상속·증여) 금액은 만들지 않고 외부 카드로만 잇습니다. 기능 키는 모두 꺼 둔 채 출하합니다. 마이그레이션은 84번만 씁니다(85는 예비로 비워 둠).

## 3. 데이터 이름

- 마이그레이션 `20261025000084_w10b_wetax_links.sql`: `wetax_links`(key, kind home·filing·payment·refund·app, tax_kind, label, url, status, `fail_count`, fallback_key, checked_at) · `wetax_link_checks`(link_key, run_key 유일, 추가만) · `official_links.kind`에 `nts_guide`·`law_center`·`edu_site` 추가(씨앗 3행은 주소 비움) · 공개 읽기 뷰 `public_active_ruleset`·`public_active_determination`·`public_calc_gate`(활성 행·건수만).
- 판정표에 선택 칸 `questions`(field, text ≤ 60자, kind yesno·count·date, help)를 더했습니다(`packages/tax-engine/src/determination.ts`). 환급 문진표가 판정표와 함께 서명되도록 하기 위한 것입니다.
- 판정표 입력(facts) 칸 이름(감면 판정표 작성 규칙): `owner_type` `property_kind` `cause` `price` `house_count` `exclusive_area_sqm` `is_adjusted_area` `first_home`. 값이 없는 칸은 넣지 않아 "직접 확인 필요"가 됩니다.
- 코드: `apps/web/lib/calc/*`(순수 함수·시험), `lib/server/public/calc-tools.ts`·`calc-props.ts`(공개 읽기), 라우트 `app/(site)/calc/{acquisition,holding,refund,compare,accuracy}`.
