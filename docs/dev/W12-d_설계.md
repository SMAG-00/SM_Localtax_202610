# W12-d 도우미 창 모드 전환·진입점·대화 기록·한도·고지: 구현 기록 (개발 문서)

4단계 설계(`docs/dev/4단계_설계.md`) 1장 W12-d 행, 1.1 단계 d1~d8, 2.1 번호 168~171, PRD-04 CHAT-15·HOME-10·ASK-10~13·COMPLY-01~03·ACC-05에 맞춘 구현 기록입니다. 설계와 다르면 설계가 맞고 이 문서를 고칩니다. (2026-10-27 작성, 진행 중)

## 3. PO 입력 목록

- 모드 고지 문구, 답변 하단 고지, 처리방침 문단, 고지 버전과 승인 (`ask_mode_notice`, 법률 감수)
- 4c에서 모드 버튼을 보일 계정 종류 (`ask_mode_targets`)
- 회원 대화 보존 기간 (`ask_retention.member_days`, 초안 90일)
- 하루 한도 값은 `ask_limits`(비회원 3·일반 10·프리미엄 100)로 이미 시드되어 있습니다
- 카카오 앱 등록(d7), 게이트 리포트(W12-e)
