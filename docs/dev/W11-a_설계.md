# W11-a 판정표·요건 사전·감수 콘텐츠 기반 + W11-0 0차 공통: 구현 기록 (개발 문서)

3단계 설계(`docs/dev/3단계_설계.md`) 1장 W11-0·W11-a와 2.1·2.2·3장에 맞춘 구현 기록입니다. 설계와 다르면 설계가 맞고 이 문서를 고칩니다. (2026-10-25 작성)

지키는 선: 이 단위의 코드와 시험 자료에는 실제 법령·세무 문장, 세율·공제·기한·한도 값, 감면·판정 요건, 달력 날짜를 쓰지 않습니다. 판정표·가이드·요건 사전은 빈 칸으로 출하하고(씨앗 0행) 시험 자료는 지어낸 값에 `시험용` 표시를 붙입니다. SM 해설은 AI 작성·미감수 값으로 보고 서명 전에는 `draft`로만 둡니다. 기능 키는 모두 꺼 둔 채 출하합니다. 국세 금액은 만들지 않습니다.
