# W7 최적화·제휴 준비 완성 — 설계 약속 (개발 문서)

PRD-01A 4.15 OPT-01~03·06~10, 4.17.3 NAV-16~20, SEO-01·04의 남은 부분을 구현할 때 DB·서버·화면·시험이 같은 이름과 같은 규칙을 쓰기 위한 약속입니다. W2-c·W6·W7c 설계와 같은 모양으로 짧게 씁니다. 이 문서와 PRD가 다르면 PRD가 맞고 이 문서를 고칩니다.

**이 문서와 구현은 실제 법령·세무 문장, 규정 원문 수치, 실제 검색어·매체명을 쓰지 않습니다.** 규칙·화면 틀·기준을 읽는 자리만 정합니다. 시험 자료는 모두 지어낸 값(`*.example.test`, 가상 제목)입니다. 규정 합격선·배점·기사 수 기준은 코드와 설정 기본값에 두지 않습니다(NAV-13 저장소 검사 유지).

**이미 있는 것(W1-b·W2-a·W2-c·W4)**: `packages/seo-lint`·`similarity`·`structured-data` 엔진과 견본 시험, 발행 판정 `lib/server/articles/gate.ts`(유사도 → 구조화 데이터 대조 → 점검 → 편집 판정), 점검 패널 `CheckPanel`(저장된 기사 기준)·`GET …/check`·발행 422·`seo_checks` 기록, 기사·인물·행사·경로 표시 JSON-LD(일부 화면), `/admin/news-readiness`(규정 버전 `news_partner_requirements`·점검 기록 `news_partner_checks`·3/6/12개월 지표), `query_terms`(검색어 집계), 유입 경로 `ai_answer_engine` 분류, `first_published_at` 변경 거부 트리거, 개정 트래커 `amendment_events`, `source_review_queue`. **없는 것**: `sitemap.xml`·뉴스/이미지 사이트맵·RSS·`robots.txt` 경로 전부, 저장 전 입력 기준 점검, 키워드 반복·제목 위계·리드 직접 답 점검, 규정 버전 기반 유사도 기준 연결, `NewsMediaOrganization`(/about), 대부분 화면의 `BreadcrumbList`, 신선도 검수 큐, `ai_citation_samples`, 서치 콘솔 수집, `partner_readiness_monthly`·월 마감·3개월 조합, 부정평가 누적.

**먼저 고칠 사실(조사에서 발견)**: 루트 `app/layout.tsx`가 `robots: { index: false }`를 고정해서 `SITE_INDEXING=on`이어도 지역 허브 몇 곳 말고는 모든 화면이 `noindex`로 남습니다(SEO-04 "on에서 색인 대상 `noindex` 0%" 위반). 3단계에서 `siteIndexing()`을 읽는 한 함수로 바꿉니다.

범위 밖(P1, 이후): OPT-04 질의 지도(`query_clusters`) · OPT-05 엔티티 그래프(GEO 정식 명칭 점검 포함) · OPT-11 · OPT-12 · NAV-21~23. `Book`·`Course`(W8 스토어·교육원)와 `Dataset`(정량형 원자료 공개 화면 없음)은 해당 화면이 생기는 작업 단위에서 같은 생성기로 더합니다.

## 3. 규칙 요약

- **색인 대상 판정(한 함수)**: 공개 상태 + 본문 있음 + 광고/공동 기획 아님(기사·RSS·뉴스 사이트맵; 일반 사이트맵은 광고 기사도 `noindex`가 아니면 넣되 표기 유지) + 해당 기능 키 켜짐 + 빈 지역·빈 하위 분야·기사 적은 지역 제외(`region-index-logic` 재사용). 사이트맵·화면 `robots` 메타·`canonical`이 이 함수 하나에서 나옵니다.
- **`SITE_INDEXING=off`**: 모든 HTML에 `noindex`, `robots.txt` 전체 차단 + `Sitemap:` 줄 없음, 사이트맵·RSS 404, IndexNow·서치 콘솔 사이트맵 제출 0, 크롤러 허용 값보다 우선.
- **`SITE_INDEXING=on` 전환 점검**(`/admin/seo` + `post-deploy.sh`): `crawler_policy.ai_training.decided`·`search` 비어 있음 → 실패, 사이트맵 URL 표본 canonical, 구조화 데이터 오류 수, 소유 확인 기록(수동 체크).
- **점수 문구**: 점수는 내부 품질 지표. 패널·대시보드에 순위·노출 예측·'인정'·'선정 예정' 문구 0.
