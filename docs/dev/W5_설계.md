# W5 부동산개발금융(구조 해설·사례 템플릿·통계 트래커·칼럼) — 설계 약속 (개발 문서)

PRD-01B 8장 W5(`/finance` 하위 메뉴·구조 해설(구조도 + 표)·감수·사례 템플릿(`finance_cases`·반론)·규제·통계 트래커·칼럼, 금지 범위 검사, 자본시장법 검토 전 플래그 — DF-01~05 · DF-09)를 구현할 때 DB·서버·화면·시험이 같은 이름과 같은 규칙을 쓰기 위한 약속입니다. W4 설계와 같은 모양으로 짧게 씁니다.

**이 문서는 실제 금융·법률·세무 내용(구조 설명, 사례 사실, 통계 값, 규제 비율, 투자 관련 문구)을 쓰지 않습니다.** 화면 틀·입력 방식·승인 흐름·빈 내용일 때의 표시만 정합니다. 실제 내용은 편집국이 공식 원문을 보고 입력하고, 세무 감수위원(PO)과 법률 검토자가 확인합니다. 운영 DB의 씨앗은 비어 있거나 서명이 없는 상태입니다. 시험 자료는 모두 지어낸 값입니다.

**MVP 방침(PO 2026-10-24 "MVP를 우선 만들어서 사용해보려고 해 … 빨리빨리")**: 관리 입력 → 공개 화면이 끝까지 이어지게 만들고, 지켜야 할 선(기본 거부 RLS·공개 뷰·추가만 표·반론 기록·투자 권유 0)은 그대로 둡니다. 장식과 긴 시험은 줄입니다.

## 11. 기록

- 반론 기록: 사례마다 요청일·방법·답변 상태(답변·무응답·거절). 실명 기업이면 셋 모두 있어야 편집 승인과 발행이 됩니다. 메모는 내부용입니다.
- 감수 기록: 구조 해설 승인본마다 세무 서명자·시각, 법률 확인자·일자가 남습니다(추가만).
- 감사 로그: 관리 화면의 쓰기는 모두 `finance.*` 동작으로 남깁니다.
- 법률 검토 기록은 설정 `finance_legal_review`에 둡니다. 이 기록이 승인 상태가 아니면 기능 키 `finance`는 켜지지 않습니다.
