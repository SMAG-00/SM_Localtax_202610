## 12. 결정

| # | 결정 | 이유 |
|---|---|---|
| 1 | 새 직원 역할을 만들지 않고 권한 이름(ACTIONS)만 더함 | 역할이 늘면 DB 역할 제약·역할 충돌 규칙·관리 화면이 함께 바뀜. 서명=감수위원(`reviewer`), 승인=관리자는 기존 역할로 표현 가능 |
| 2 | 설정 씨앗 값은 빈 객체 | 일수·횟수·시각·한도는 감수·PO 결정 입력이라 AI가 값을 쓰지 않음 |
| 3 | `DATA_API_*`는 `DATA_API_KEY` 하나만 먼저 등록 | 원천별 이름은 W10-h가 원천이 정해질 때 더함 |
| 4 | `ruleset.sign`은 관리자도 거부 | 기존 `review.tax_review`와 같은 원칙(감수 서명은 감수위원만, RULE-04) |
