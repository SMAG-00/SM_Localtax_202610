### 11.2 W10-a 본체

**a1 엔진 가지치기 복사 - 완료.** `packages/tax-engine`(`@ltr/tax-engine`)에 SM 엔진(커밋 `ce87823f…`)을 읽기만 해서 복사했습니다. 복사한 것: acquisition·holding·oligopoly·brackets·formulas·money·dates·types·version·schema·result와 시험 7개(acquisition·holding·oligopoly·core·purity·redevelopment·schema) + `test/ruleset.ts`. 복사하지 않은 것: `transfer.ts`·`compare.ts`와 양도·비교 시험 전부. `schema.ts`는 양도 구역과 `RulesetSchema.transfer`, `result.ts`는 양도 중간 단계(`TransferBreakdown`·`breakdown`·`setBreakdown`)를 삭제했고, `index.ts`는 새로 써서 `calcAcquisition`·`calcHolding`만 내보냅니다(`oligopoly`는 공개 진입점에 넣지 않음). 복사본 시험 126개 전부 통과(기준선), 새로 쓴 `test/boundary.test.ts` 7개(국세·비교·과점주주 계산 함수 export 0, 계산 함수는 취득·보유 2개뿐, 룰셋 최상위에 국세 구역 0, `SOURCE.json` 파일별 SHA-256 일치·LF)까지 133개 통과. `SOURCE.json`에 원본 커밋과 파일별 원본·복사본 SHA-256, 상태(verbatim·modified·pruned)와 변경 사유를 기록했습니다. `check-national-tax` 통과(NT1~NT5 위반 0). 로컬에는 `FORBIDDEN_IDENTIFIERS` 값이 없어 `check-forbidden-ids`는 건너뜀으로 끝납니다(CI에서 실행).

**a2 룰셋 초안 파일 - 완료.** `rules/2026.01.json`·`2026.07.json`·`2026.08.json`: SM 룰셋에서 최상위 `transfer` 구역을 삭제하고 `status: "draft"`를 더했습니다(값은 SM이 가진 AI 작성·미감수 값 그대로, 감수 서명 전 draft). `rules/versions.lock.json`(파일 SHA-256 잠금)·`rules/bundle.json`(서명 기록이 있는 버전만, 지금 0개)·`scripts/check-rules.mjs`(R1 이름·버전·draft / R2 잠금 일치 / R3 직전 커밋 잠금 항목 변경·삭제 금지 / R4 번들은 서명 기록 필수)를 만들고 `scripts/ci/static.sh`에 한 줄 더했습니다. 시험 `scripts/__tests__/check-rules.test.mjs` 9개.

## 12. 결정

| # | 결정 | 이유 |
|---|---|---|
| 1 | 새 직원 역할을 만들지 않고 권한 이름(ACTIONS)만 더함 | 역할이 늘면 DB 역할 제약·역할 충돌 규칙·관리 화면이 함께 바뀜. 서명=감수위원(`reviewer`), 승인=관리자는 기존 역할로 표현 가능 |
| 2 | 설정 씨앗 값은 빈 객체 | 일수·횟수·시각·한도는 감수·PO 결정 입력이라 AI가 값을 쓰지 않음 |
| 3 | `DATA_API_*`는 `DATA_API_KEY` 하나만 먼저 등록 | 원천별 이름은 W10-h가 원천이 정해질 때 더함 |
| 5 | zod는 4.6.7을 `@ltr/tax-engine`에 선언(lock에 이미 있던 버전, `pnpm install --offline`으로 lock importers만 갱신) | 새 패키지가 아님. SM은 3.24.1. 코드 변경은 `schema.ts`의 `refine` 한 줄 타입 좁히기뿐이고 복사본 시험은 그대로 통과. `SOURCE.json` notes에도 기록 |
