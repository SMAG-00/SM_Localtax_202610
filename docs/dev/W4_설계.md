# W4 부동산·`/local` 허브(행정구역 전국·지자체 허브 골격·지역 기사 CMS·프로젝트 트래커·분양 정보·개발방법 비교·상속·증여 안내) — 설계 약속 (개발 문서)

PRD-01B 8장 W4(행정구역 전국 적재·`/local` 허브 골격(LG-08 순서 — 핫뉴스·행사안내 블록은 W6 플래그)·지역 기사/공식 자료 CMS·REG1-17 게이트·지역 검색·얇은 페이지, `/realestate` 허브·지자체별 부동산 블록·프로젝트 트래커·분양 정보 분리·공공누리·개발방법 비교·특례법 확인·부동산 칼럼·상속·증여 안내 — PR-01~05·07~11·13·14 · REG-01·06~10 · REG1-01·02·07·09~15·17 · FAM-01·02·08, 블록 순서는 LG-08)를 구현할 때 DB·서버 함수·화면·시험이 같은 이름과 값을 쓰도록 정한 약속이다. 증거: 단계 원문 100% 연결 · 추천 기능 0(PRD_최종 §11.1 W4) · 가격·수익률 칸 0(스키마 검사) · 시범 지역 최소선 판정 리포트 · 360/1280px E2E · 지역 → 세금 링크 검증. 이 문서와 PRD가 다르면 PRD가 맞고 이 문서를 고친다. W2-a~W3에서 정한 것(값 목록·공개 읽기·캐시·기능 키·감사)은 그 설계 문서를 그대로 따른다.

**이 문서는 실제 내용(지역 통계·정비사업 사실·고시 번호·법령 문구·숫자 요건 값·세무 문장·행정구역 코드)을 쓰지 않는다.** 화면 틀·편집 방식·승인 흐름·빈 내용일 때의 표시만 정한다. 실제 내용은 편집국이 공식 원문을 보고 입력하고 세무 감수(책임자 PO, 세무사 — 보조 1명 교차 확인)가 승인한다. **행정구역 코드는 공식 원본 파일(행정표준코드관리시스템 「법정동코드 전체자료」)에서만 온다** — AI·개발자가 시·군·구 코드를 손으로 만들거나 추측하지 않는다. 시험 자료의 지역·프로젝트·개발방법은 `시험용` 표시가 붙은 가짜이고, 가짜 행정구역은 법정동코드에 없는 접두 `99`를 쓴다 [확인 필요 — 원본 파일에 `99`가 없는지 2단계에서 대조]. 지역 = 전문 뉴스 허브이고 관광·맛집·지도·TourAPI는 만들지 않는다(PRD-X). 양도세는 SM 부동산 세금 플랫폼의 '팔 때' 메뉴로 연결만, 상속세·증여세는 「안심 상속증여계산기」로 연결만 하고(입력값 비전달), 국세 금액은 어디에서도 만들지 않는다. SM 플랫폼은 바꾸지 않는다.

## 6. 권한과 감사

- 행정구역 적재 적용·폐지·후속 지정·옛 주소: 관리자(PO)만(`region.manage`). 차이 보고(`dry_run`)는 개발 담당도 만든다.
- 지역 기사 편집 분야 판정·별도 상품 큐 보내기: 편집 책임자(`regional.judge` — 12장 #7). `ad_ops`·`brand_ops`는 판정·정렬·블록 배치 변경 403 + 감사(PRD_최종 §9.1).
- 프로젝트·분양·개발방법 입력: 편집 책임자 이상. 공개 전환: 편집 책임자, 세무 감수가 필요한 것(템플릿·개발방법)은 `reviewer` 서명 뒤.
- 특례법 확인 기록: 관리자(PO)만.
- 지역 편집비 입력: 관리자(운영 책임자).
- 모든 쓰기는 감사 로그. 이벤트·점검 요청에 이용자 주소·좌표·검색어 원문 0.

## 7. 세무 감수·편집 흐름 (내용은 사람이 채운다)

1. 행정구역: PO(또는 PO가 맡긴 사람)가 공식 원본 파일을 받는다 → 개발이 차이 보고서를 만든다 → PO 승인 → 데이터 마이그레이션.
2. 지역 기사: 기획(편집 분야·공익적 질문) → 취재 → 공식 자료 입력(원문·발표기관·기준일·확인일·공공누리) → 편집 판정·checklist 3항목 → 세무 감수(세금·법률 주장이 있을 때) → 승인 → 공개.
3. 프로젝트: 편집국이 사업 유형·단계 목록 초안 → PO·법률 감수 → 설정 입력. 단계마다 고시 원문을 받아 기록 → 공개 전환.
4. 단계별 「지방세로 읽기」·개발방법 비교·숫자 요건: 편집국 초안 → PO 서명 + 보조 교차 확인(고위험 — PRD-00 6장).
5. 분양 정보: 공식 공고를 보고 입력. 시행사 원고는 `sponsored`로만.
6. 상속·증여: 입문 기사·상황 4종을 편집국이 쓰고 PO가 감수. 국세 부분은 외부 연결만.

AI는 초안·분류 보조만 하며 행정구역 코드·고시 번호·숫자 요건·세무 문장을 생성해 저장하는 경로를 만들지 않는다.

## 8. 시험 원칙

- 시험용 지역은 접두 `99` 가짜 코드와 `시험용` 이름, 시험용 프로젝트·개발방법·상황은 `시험용` 표시. 운영 시드에 들어가지 않고, 시험 뒤 public 표 행 수가 시험 전과 같다.
- 실제 지명이 필요한 시험(2.9 DB 시험·성능)은 2단계 뒤 실제 `regions`만 쓴다 — 가짜 코드에 실제 지명을 붙이지 않는다.
- 같은 규칙은 DB와 서버 함수 양쪽에서 시험한다(한쪽만 우회한 삽입도 실패).
- 모의 객체는 외부 사이트(원문 다시 받기)에서만 — 로컬 가짜 서버. 나머지는 실제 DB, RLS는 anon 키로.
- 검사 스크립트(가격 칸·고정 문구 숫자·국세)는 위반 파일을 일부러 넣어 실제로 잡는지 본다.
- 날짜 경계는 KST(마감일 23:59/00:00, 만료 365/366일, 재방문 30/31일).
