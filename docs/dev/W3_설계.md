# W3 지방세(개정 트래커·브리핑·해석 해설·칼럼·인물·SM 계산기 연결) + 브랜드 부분 — 설계 약속 (개발 문서)

PRD-01B 8장 W3(개정 트래커(수동)·개정 브리핑·`legal_docs`와 해석 해설·칼럼 필자 체계·`/calc` SM 계산기 5종·`official_links` 확장·링크 점검 배치·국세 미산출 검사·홈 핵심 메시지/4대 분야 카드/허브 지방세 포인트 — TX-01·02·03·06·07·08·09·14~17·CORE-02)와 PRD-01C 9장 W3(브랜드 부분 — BR-01·02·03·04·07·08)을 합친 작업 단위다. 증거: 2026 개편안 트래커 단계별 재현(PRD_최종 §11.1) · `입법예고` → `국회 제출` 시나리오 · SM 카드 표식 값 0 · 링크 점검 7·8일 경계 · 증빙 없는 약력 렌더 0 · 서명 기록 없는 '감수 김의효' 0 · '50년' 승인 전 0.

**이 문서는 세법 내용(개정안 문구·세율·조문·해석 요지)과 브랜드 증빙(경력·직함·'50년' 산정 기준)을 쓰지 않는다.** 화면 틀·편집 방식·승인 흐름·빈 내용일 때의 표시만 정한다. 실제 내용은 편집국이 입력하고 세무 감수(책임자 PO, 세무사)가 승인한다. 시험 자료의 개정안·해석·필자는 `시험용` 표시가 붙은 가짜이고 실제 세법처럼 읽히지 않게 한다. 세액은 검수 엔진만 만들고 AI는 안내만 하며, 국세 금액은 어디에서도 만들지 않는다. 양도세는 별도 계산기가 아니라 SM 플랫폼의 '팔 때' 메뉴(`/transfer`·`/calc/transfer`)로 연결만, 상속세·증여세는 「안심 상속증여계산기」로 연결만 한다(입력값 비전달). SM 플랫폼은 바꾸지 않는다.

## 6. 권한과 감사

- 개정 단계 기록·정정: `editor` 이상. 세무 감수 승인(`tax_review`): `reviewer` 역할 — 작성자 본인 승인 거부는 W2-a 그대로.
- 칼럼 발행 승인은 편집국(`editor`). 필자 계정은 원고 제출·감수 서명만. 필자 = 승인자 거부, `brand_ops`는 승인·정렬 거부 + 거부 감사 로그(BR-08). `editor`+`brand_ops` 동시 부여는 DB가 이미 거부한다.
- `career_claim_approved`·`brand_copy` 토글·동의서 등록/철회·증빙 승인: PO(관리자)만, 감사 로그에 남는다.
- 링크 점검 수동 기록: `editor` 이상, 점검자 기록.
- 점검 요청·카드 이동에 이용자 정보 0.

## 7. 세무 감수·편집 흐름 (내용은 사람이 채운다)

1. 편집국이 개정안을 만들고 단계마다 날짜·원문 URL·스냅샷을 입력 → PO(세무사)가 `public`으로 전환한다.
2. 브리핑 기사는 `article_amendments`로 연결, `확정 아님`은 설정 기준으로 서버가 계산한다(손으로 켜지 않음).
3. 해석 원문은 편집국이 `legal_docs`에 입력, 해설은 별도 기사. 세무 감수 서명 뒤에만 발행.
4. 칼럼은 필자 검증 → 계약 기록 → 이해관계 확인 → 편집 승인 → 발행.
5. 브랜드 증빙·동의서·'50년' 승인은 PO가 입력·승인. 승인 기록 전 화면은 비거나 숨는다.

AI는 초안·분류 보조만 하며 개정안 문구·세율·해석을 생성해 저장하는 경로를 만들지 않는다.

## 8. 시험 원칙

- 시험용 가짜 개정안·해석·필자·증빙은 `시험용` 표시가 있는 시험 자료이며 운영 시드에는 들어가지 않는다.
- 같은 규칙은 DB와 서버 함수 양쪽에서 시험한다(단계 기록 조건, 발행 검사).
- 모의 객체는 외부 사이트 점검에서만(로컬 서버로 2xx/4xx/5xx/시간 초과 재현). 나머지는 실제 DB.
- 국세 검사와 '50년' 검사는 위반 파일을 일부러 넣어 검사가 실제로 잡는지 확인한다.

## 9. 개인정보·저작권

원문(예규·판례·심판)은 권리 상태 `confirmed`만 공개, 판례·심판은 비실명 확인 필수. 칼럼은 계약 범위 밖 재수록·AI 색인 금지. 이름·사진·서명·음성은 동의서 범위 안에서만 쓰고 철회하면 다음 요청부터 내린다.

## 10. 제외와 위험

만들지 않는 것: 개정 자동 감지(PRD-02, W10), 해석 DB 검색·3단 보기(TX-10·11), 지방세 50문 50답·한 줄 평(BR-05), 영상·낭독·과거 칼럼 아카이브(BR-06), 스토어 상품 카드(W8), 전문가 소개(W7c), 자체 세액 계산(영구 제외). 위험: 계산기 주소·이용 조건 미확정(공개 지연), 상대 사이트가 자동 요청을 막으면 수동 점검만, 브랜드 증빙 미확보 시 인물 페이지·시그니처 칼럼 공개 지연.
