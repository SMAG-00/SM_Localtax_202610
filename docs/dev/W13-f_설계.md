# W13-f 전문가 계산기 설계 (CALC-17 · CALC-18 · CALC-19)

5단계 설계(`docs/dev/5단계_설계.md`)의 W13-f 행을 구현할 때 정한 약속입니다. 이 문서와 PRD가 다르면 PRD를 따릅니다. (2026-10-27)

## 1. 범위와 선

- 지방세 금액만 계산합니다. 양도·상속·증여 금액, 종합부동산세·농어촌특별세·인지세 줄은 화면·API·내보내기 어디에도 없습니다(NT1~NT9 유지).
- 세율·구간·과세 범위는 전부 룰셋에서 읽습니다. 코드에는 숫자 상수가 없습니다. 법률·세무 문구는 쓰지 않고 자리 표시(빈 칸)로 둡니다.
- 감수된 전문가 룰셋이 없으면 세 계산기는 모두 닫힙니다(`unsupported`, 화면 404). 운영 룰셋 자리(`lib/calc/expert/ruleset.ts`)는 `null`이고, PO가 감수본을 줄 때만 채웁니다.
- SM 엔진(`oligopoly`, `compare`)은 반입하지 않습니다. 이 저장소의 `@ltr/tax-engine`에 이미 있는 `calcOligopoly`(2단계 복사본)를 상장 여부 분기로 감싸기만 합니다.
- 계산은 브라우저에서만 합니다. 서버 계산 API 0, 입력값 저장·전송·이벤트 0.

## 2. 단계

| 단계 | 내용 | 파일 |
|---|---|---|
| f1 | 엔진 틀·전문가 룰셋 스키마·시험용 룰셋·게이트 연결 | `packages/tax-engine/src/expert.ts`(진입점 `@ltr/tax-engine/expert`), `apps/web/lib/calc/expert/{gate,ruleset}.ts` |
| f2 | CALC-17 상장 여부 분기·"모르겠어요"는 두 시나리오 나란히 | `calcOligopolyByListing`, `/calc/oligopoly` |
| f3 | CALC-19 법인지방소득세: 과세표준(입력값) → 세율 구간(최소 범위). 안분·공제·감면은 PO 결정 전까지 넣지 않음 | `calcCorporateLocalIncome`, `/calc/corporate-local-income` |
| f4 | CALC-18 개인 vs 법인: 취득세·재산세 계열만(허용 코드 목록), "국세는 이 비교에 포함되지 않습니다" 고정 줄, SM 비교 계산기 새 창 링크(주소에 입력값 0) | `calcEntityLocalTaxes`, `/calc/entity` |
| f5 | 수용 E2E(작성만), 공식 결과 대조 도구는 W10-a 것을 쓰고 대조 데이터는 PO·감수 입력 | `e2e/w13f-acceptance.test.mjs` |

## 3. 게이트

- 열림 조건 = 기능 키 `expert_calc`와 `calc`가 켜짐 ∧ `calc_gate_status`에 해당 세목 줄이 있고 `is_open` ∧ 엔진 해시 일치 ∧ 전문가 룰셋(CALC-18은 기본 룰셋)이 있음 ∧ 화면 고정 안내 문구가 채워짐. 하나라도 빠지면 닫힘.
- 지금 `calc_gate_status`에는 세목 `oligopoly`·`entity`·`corporate_local_income` 줄이 없으므로 항상 닫힙니다. 세목 추가(`accuracy_cases.tax_kind` 허용 값·뷰 묶음·대조 실행기)는 PO가 감수된 룰셋과 공식 결과 30건·감수 표본 50건을 줄 때 마이그레이션 213으로 합니다(번호 예비). 이번 단위는 마이그레이션이 없습니다.

## 4. PO 입력이 필요한 것

감수된 상장 여부별 과세 범위, 법인지방소득세 세율 구간표, 법인지방소득세 범위 결정(5단계 설계 5장 #21·#22), 공식 결과 30건·감수 표본 50건, SM 비교 계산기·과점주주 계산기 링크 주소(`official_links`), 화면 고정 안내 두 줄(코드에 글자가 없고 `lib/calc/expert/ruleset.ts`의 `PRODUCTION_EXPERT_NOTICES_RAW` 자리에서 읽으며, 비면 계산기가 열리지 않습니다). 초안 — PO 감수: CALC-18 "국세는 이 비교에 포함되지 않습니다", CALC-19 "과세표준은 입력값이며 세무조정은 하지 않습니다" (PRD-05·5단계 설계가 정한 초안이며 AI가 확정하지 않습니다).
