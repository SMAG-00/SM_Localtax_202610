# W11-f 기관 구독·좌석·세금계산서·프리미엄 리포트: 설계와 구현 기록 (개발 문서)

3단계 설계(`docs/dev/3단계_설계.md`) 1장 W11-f·2.1·3장·5장 #12~#17·6장과 PRD-03 BIZ-07·PAY-04에 맞춘 문서입니다. 설계나 PRD와 다르면 PRD가 맞고 이 문서를 고칩니다. (2026-10-25 작성)

지키는 선: 계약서·보안 확인표 문항·리포트 본문·미리보기·가격·법률 검토 기록은 모두 빈 칸입니다(PO·법률·편집국 입력, AI 작성 0). 시험 자료는 `시험용` 표시와 지어낸 값입니다. 기능 키(`institution_subscription`·`premium_reports`·`institution_inquiry`)는 꺼 둔 채 출하합니다. 기관 온라인 결제는 없습니다(PO 기본값 #13: 계약서·세금계산서만). 국세 금액은 어디에도 없습니다. 제품 이름 글자는 `packages/ui/src/brand.ts`에서만 읽습니다.

## 1. 병렬 작업을 위해 W11-0에서 옮긴 것

W11-0(마이그레이션 110)이 다른 작업 공간에서 동시에 만들어지므로, W11-f가 쓰는 아래 항목은 **131과 코드 목록에 W11-f 몫으로 더합니다**. 리드가 합칠 때 같은 줄이 겹치면 한쪽을 지웁니다.

## 5. 기관 계약 시험 E2E (f7) — `e2e/w11f-acceptance.test.mjs`

가짜 PG는 쓰지 않습니다(기관 결제 없음). 단계: ① 기능 키 켬(시험 DB) ② 견적 요청 접수(동의 없음 422·이메일 오류 422·접수 성공) ③ 운영자가 기관·계약 등록, 확인표 미승인 상태에서 개통·초대 거부 ④ 확인표 승인 → 개통 ⑤ 기관 관리자가 좌석 n개 초대, n+1번째 거부 ⑥ 수락한 좌석 회원은 리포트 전문, 비좌석 회원·비회원은 HTML·RSS·검색·JSON-LD·API에 전문 0, 좌석 → 비좌석 순서에서 누출 0 ⑦ 회수 다음 요청부터 거부 ⑧ 종료일 당일 허용·다음 날 00:00 KST 거부(시각 주입) ⑨ 세금계산서 요청·수기 발행 기록 ⑩ 정기 작업 정리 ⑪ 견적 파기.

## 6. 결정

모두 `권고안으로 진행 (PO 위임)`입니다. 법률·세무 내용은 [감수 필요]·[법률 검토]로 표시했습니다.

| # | 결정 | 이유 |
|---|---|---|
| 1 | 좌석 수 = 초대 중 + 활성 좌석, 계약 행 잠금 아래에서 셈 | 동시 초대에도 n+1번째 0 |
| 2 | 초대는 링크 토큰(해시만 저장)이고 메일 주소는 저장하지 않음 | 개인정보 최소. 링크 전달은 기관 관리자가 직접 |
