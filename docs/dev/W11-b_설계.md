# W11-b 부동산 세금 전 주기·주택 수·총비용·상속·증여 다음 확인: 구현 설계와 기록 (개발 문서)

3단계 설계(`docs/dev/3단계_설계.md`) 1장 W11-b·1.1·2.1(마이그레이션 115~117)·3장 b행·5장 #18·#19와 PRD-03 RE-01~05·FAM-05에 맞춘 구현 문서입니다. 설계와 PRD가 다르면 PRD가 맞고 이 문서를 고칩니다. (2026-10-26 작성)

지키는 선: 이 단위의 코드와 시험 자료에는 실제 법령·세무 문장, 세율·공제·기한·한도 값, 판정 요건, 달력 날짜를 쓰지 않습니다. 가이드·판정표·요건 사전은 빈 칸으로 출하하고 시험 자료는 지어낸 값에 `시험용`을 붙입니다. 국세 금액(양도·상속·증여)은 만들지 않고 SM·외부 카드로만 잇습니다(`scripts/check-national-tax.mjs` NT1~NT9). 계산 중 네트워크 0, 입력값은 저장·전송하지 않습니다(브라우저 메모리에만). 기능 키(`tax_lifecycle`·`house_count`·`total_cost`)는 모두 꺼 둔 채 출하합니다. 사이트 이름은 `packages/ui/src/brand.ts`에서만 읽습니다.

## 3. 데이터 이름과 약속

- 가이드 절 약속: `sections[]`는 가이드 관리 화면 형식 그대로 `{ heading, body }`(다른 칸은 저장 거부)이고, 절의 탭·원인·세목 배지는 `facts.section_map = [{ index, tab: "acquire"|"hold"|"transfer", cause?: "PAID"|"INHERITANCE"|"GIFT", tax_kind: "local"|"national", sources?: string[] }]`에 둡니다. 지도에 없는 절·모양이 틀린 절은 렌더하지 않습니다(어정쩡하게 열리지 않음).
- 확인 목록: `facts.transfer_checklist: [{ id, label }]`. 기준 금액·기간은 label 안의 감수 문장이며 코드에는 없습니다.
- 정책: 설정 `total_cost_policy` = `{ max_holding_years, max_rate_bp, max_extra_items, compare_years:[n,m] }`. 값은 PO 입력(5장 #18 권고: 부대비용 2개·만기 일시 상환·상한 10년·매매만), 비어 있으면 기능이 열리지 않습니다.
- 총비용 규칙: 연 이자 = 원금 x 연 금리(만분율 정수) / 10000, 원 미만 버림, 매년 같음. 금리 0이면 이자 0원, 보유 0년이면 보유세 0회·이자 0원. 공시가격을 "모르겠어요"로 두면 추정하지 않고 보유세를 빼고 "미포함" 칩. 취득 원인은 매매만.
- 판정 입력은 브라우저 메모리에만 있습니다. 판정표는 `public_determination_tables`(a4)에서 렌더 때 함께 내려옵니다.
