# W13-c 분할 화면·쟁점 타임라인·관련 자료 패널 v2 설계 (LAW-07~10 · LINK-02)

5단계 설계(`5단계_설계.md`) 1.1절 W13-c 행과 PRD-05 LAW-07~10·LINK-02를 구현하는 약속입니다. 법령·세무·회계 문장, 기준 점수 값, 계정과목 매핑 내용은 쓰지 않고 구조만 만듭니다. 마이그레이션은 202~205만 씁니다(204·205 예비). AI 호출은 없습니다 — 패널 추천은 저장된 연결(`links`)과 규칙으로 고르며 새 문장을 만들지 않습니다.

## 1. 결정

| 항목 | 결정 |
|---|---|
| 연결 표 확장(202) | `links`에 `reason`(추천 이유 한 줄, 120자)·`similarity`(0~1)를 더하고 `origin`에 `similarity`를 더합니다(`origin`은 W10-d에 이미 있어 값만 넓힙니다). 시작 종류에 `pub_node`·`issue_article`(지식창고 노드·월간지 기사)을 더합니다. 유사도 연결은 이유와 점수가 필수입니다 |
| 공개 뷰 | v1 `public_links`는 칸을 바꾸지 않고 유사도 연결만 뺍니다(v1 화면 불변). v2 `public_links_v2`는 양 끝이 공개일 때만, 지식창고 시작은 승인+공개 권리 확인분만 보입니다. 본문 칸은 어느 뷰에도 없습니다 |
| 유사도 기준 | 설정 `link_similarity_threshold`가 `{"min": 숫자}`일 때 점수 ≥ min인 연결만 보입니다(경계 포함). 비어 있거나 숫자가 아니면 유사도 카드 0입니다. 기준 값은 PO 입력이고 코드에 상수가 없습니다 |
| 유사도 연결 넣기 | `link_add_similarity`(service_role 배치 전용): 공개 상태 자료만, 이유·점수 필수. 새 문장은 만들지 않습니다 |
| 패널 v2 카드 | 제목 + 유형 칩 + 추천 이유 + 출처 표시(편집자 확인·자동 연결·유사도 추천) + 잠금 배지. 이유가 비면 관계 값(`relation`)에서 만든 글을 쓰므로 이유 없는 카드가 없습니다. 유형 필터(전체·판례·심판·해석·기사·지식창고·월간지), 정렬(최신순·관련도순) |
| 프리미엄 잠금 | 패널은 어떤 경우에도 본문을 싣지 않습니다(제목·이유·배지뿐). 지식창고 카드는 `library` 권한(`has_entitlement`)이 없으면 잠금 배지를 달고 링크는 지식창고 열람 화면으로 갑니다. 분할 화면에서 지식창고 노드 패널을 열 때 본문은 `library_read` 한 곳으로만 받습니다(미리보기·전문 판정은 DB 함수) |
| 타임라인(LAW-08) | `/law/timeline/[issue]`(`issue` = 승인된 쟁점 태그 키). 항목: 그 태그가 달린 공개 결정례·해석(결정일), 그 결정례들이 가리키는 조문의 개정판(시행일, `law_versions`). 날짜는 DB 원문 값만 쓰고, 날짜가 없거나 형식이 틀린 항목은 넣지 않습니다. 정렬: 날짜 오름차순, 같은 날은 법령 → 해석 → 심판 → 판례, 그다음 번호. 항목마다 연결 출처(편집자 확인·자동 연결)와 [원문 보기]·[분할 화면에 열기]를 달고, 같은 내용의 목록 마크업(`ol`)으로 그립니다. 항목 0건이면 빈 상태 + 원문 검색 링크. 키 `law_timeline` 꺼짐이면 404 |
| 분할 화면(LAW-07) | `/workspace/split?p=law:1:11,case:55,node:9&a=1&w=40-30-30`. 패널 구성은 주소에만 담고(서버에 저장 0), 종류는 `law`(법령:조)·`case`·`node`(지식창고 노드)·`note`(내 메모)뿐인 목록 검사를 통과한 것만 받으며 최대 3개입니다. 너비 1280 이상 3분할, 1024~1279 2분할, 1024 미만 탭입니다(경계 함수는 순수 함수로 시험). 키 `law_split` 꺼짐이면 404 |
| 공유 주소 권한 | 패널 내용은 요청마다 받는 사람의 권한으로 서버가 읽습니다. 공개 법령·결정례는 누구나, 지식창고 노드는 `library_read`가 비구독자에게 미리보기만, 내 메모는 본인만(남의 메모 번호는 "열 수 없음")입니다. 권한 없는 패널은 내용 없이 안내만 그립니다 |
| 키보드 | `Alt+←/→` 패널 이동, `Alt+Shift+←/→` 너비 ±5%p(패널 하나 최소 20%), `Alt+W` 닫기, 패널 머리 버튼으로도 모두 할 수 있습니다. 경계 막대는 `role=separator`(방향키 조절) |
| 스크랩 버튼 | 조문 화면·결정례 화면에 [스크랩]을 더합니다. 기능 키 `workspace` 꺼짐이면 렌더 0, 로그인/권한 판정은 기존 `/api/workspace/items`(`scrap_add`)가 합니다(새 API 0) |
| 3단 인쇄(LAW-09) | 기존 3단 보기에 [인쇄] 버튼과 인쇄 전용 규칙(A4 가로, 열 3개 고정 너비, 머리글에 법령명·기준일 반복, 관련 자료 열 숨김)을 더합니다. 공개 범위는 3단 보기와 같습니다(같은 데이터) |
| 계정과목 연결(LINK-02, 203) | `account_mappings`(계정과목 코드·이름, 대상 종류·번호, 관계, `std_ref` 기준 이름+조항 번호 80자, 버전, 감수 서명). 본문 칸 없음. 서명(`account_mapping_sign`, service_role)이 없는 행은 공개 뷰에 나오지 않고, 공개 뷰는 서명된 가장 높은 버전만 보입니다. `/workspace/accounts`는 계정과목 → 대상, 조문 → 계정과목 양방향을 같은 화면 문법으로 보입니다. 기능 키 `account_links` 꺼짐이면 404 |

## 2. 시험

단위(vitest): 패널 정렬·필터·이유 대체·잠금 판정, 유사도 기준(경계 min−ε/min/min+ε, 빈 값), 타임라인 정렬·같은 날 순서·잘못된 날짜 제외, 분할 주소 파서(종류·개수·형식 거부)·레이아웃 경계(1023/1024/1279/1280)·키 동작. DB(`w13c-links-accounts.test.mjs`): 유사도 기준 경계·비면 0, 공개 아닌 자료 거부, v1 뷰에서 유사도 제외, 계정과목 서명 전 공개 0·서명 뒤 공개·새 버전 규칙·삭제 거부·본문 칸 없음(스키마 검사). E2E(`w13c-acceptance`)는 작성만 하고 리드가 돌립니다.

## 3. 남은 과제 (PO 입력·후속)

- 계정과목 매핑 내용과 감수 서명(PO·세무 감수) — 입력 화면은 이번에 만들지 않았고 서명 함수까지 준비했습니다.
- `link_similarity_threshold` 값과 유사도 배치(4단계 색인 공개 뒤) — 그 전에는 유사도 카드 0입니다.
- 분할 화면의 위키·지방세봇 답변 패널은 지방세봇 대화 기록 보존이 확정된 뒤에 더합니다(지금은 법령·결정례·지식창고·내 메모).
- 칼럼(`articles` 프리미엄) 시작 종류는 예비 번호(204)로 더할 수 있습니다.
