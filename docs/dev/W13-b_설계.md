# W13-b 워크스페이스 코어 설계 (WS-01~05)

5단계 설계(`5단계_설계.md`) 1.1절 W13-b 행과 PRD-05 WS-01~05를 구현하는 약속입니다. 법률·세무 문구와 가격·한도 값은 쓰지 않고 구조만 만듭니다. 마이그레이션은 197~201만 씁니다.

## 1. 결정

| 항목 | 결정 |
|---|---|
| 권한 판정 | 기능 키 `workspace` 켜짐 ∧ 로그인 ∧ 권한 키 `workspace`(`has_entitlement`)입니다. 모드(일반·전문가) 값은 판정에 들어가지 않습니다 — 판정 함수의 입력에 모드 칸이 없습니다 |
| 모드 토글(WS-01) | 로그인 회원은 `workspace_prefs.mode`(계정), 비로그인은 쿠키 `ltr_ws_mode`(기기)에 저장합니다. 모드는 표현 밀도만 바꿉니다. 헤더에 끼우는 일은 공용 파일이라 리드가 합니다(부품 `ModeToggle`과 `/api/workspace/mode`는 준비) |
| 저장 대상(WS-03) | 대상 종류와 번호만 저장합니다: `node`·`issue`·`issue_article`·`column`(지식창고·칼럼), `article`·`law_article`·`legal_doc`(공개 자료), `agent_answer`·`copilot_result`(대화·코파일럿). 프리미엄 본문 사본은 어디에도 저장하지 않습니다 |
| 원문 버전 | 스크랩할 때 서버가 읽어 `source_version`에 저장합니다(클라이언트 값 무시). 지식창고 본문은 `library_bodies.body_hash`, 권호는 `updated_at`, 기사는 `version`, 조문은 개정판 번호입니다. 지금 값과 다르면 "개정됨"으로 표시합니다 |
| 쓰기 권한 | 새 메모·스크랩·폴더·저장 검색은 권한이 있을 때만 만듭니다. 권한이 끝난 뒤에는 만들기만 막고 본인 열람·삭제·내보내기는 남깁니다 |
| 구독 종료 후 보존(PO 결정 #10) | 어떤 코드도 개인 자료를 지우지 않습니다(계정 탈퇴의 연쇄 삭제만). 보존 기간·범위는 법률 감수 전이라 칸을 만들지 않습니다 |
| 저장 한도(WS-04) | 설정 `saved_search_limit`의 `{"max": n}`입니다. 비어 있거나 값이 틀리면 0으로 읽어 저장을 닫습니다. n번째는 성공, n+1번째는 DB 함수가 거부합니다(사용자별 잠금으로 동시 요청도 한도를 넘지 못합니다) |
| 내보내기(WS-05) | 설정 `export_excerpt_limit`의 `{"chars": n}`입니다. 비어 있으면 내보내기 전체가 닫힙니다(0). n=0이면 발췌 없이 인용 표기와 본인 메모만 나갑니다. 발췌는 권한이 있고 승인·공개 권리 확인된 지식창고 노드·기사 본문에서만 처음 n자까지입니다. 권한이 끝난 회원은 발췌 0입니다 |
| `.docx` | 새 의존을 더하지 않고 서버 전용 소형 생성기(저장만 하는 zip + 문서 XML)를 직접 둡니다. 5장 #27의 "라이브러리 1개 이하"를 지킵니다 |
| `.csv` | UTF-8 BOM, 머리 행, CRLF, 따옴표 이스케이프, 수식으로 읽힐 첫 글자(`= + - @`) 앞에 `'`를 붙입니다 |
| 인용 표기 | 항목마다 종류·번호·원문 버전·확인일을 싣고, 코파일럿·AI 유래 메모는 "AI 초안"을 싣습니다. 내보낸 날짜를 머리에 싣습니다 |
| 개인정보 | 이벤트 속성은 형식·대상 종류뿐입니다(`export_downloaded`). 내보내기 이력(199)에는 개수만 남기고 내용은 남기지 않습니다 |
| 대시보드(WS-02) | `/workspace`. 위젯: 관심 법령 개정(개정된 스크랩), 저장 검색 새 결과, 최근 메모, 최근 대화(지방세봇 기능 키가 켜졌을 때만). 맞춤 브리핑(W13-d)은 표가 생길 때까지 그리드에서 뺍니다(준비 중 위젯 0). 위젯 하나가 실패해도 나머지는 그려집니다 |

## 2. 마이그레이션

| 번호 | 내용 |
|---|---|
| 197 | `workspace_prefs`·`folders`·`notes`·`scraps` — 본인 행만 읽기 RLS(authenticated), 쓰기는 service_role |
| 198 | `saved_searches` + 한도 검사 함수 `ws_saved_search_create` |
| 199 | `workspace_exports` 내보내기 이력(개수만, 추가만) |
| 200~201 | 예비 |

## 3. 화면·API

`/workspace`(대시보드) · `/workspace/notes` · `/workspace/scraps` · `/workspace/searches`. 모두 요청마다 그리고(`force-dynamic`) 검색에 나오지 않습니다. API는 `/api/workspace/{mode,items,export}`입니다. 기능 키가 꺼지면 화면·API 모두 404입니다.

## 4. 시험

단위(vitest): 접근 판정(모드 무관), 한도 파서·절단 경계(0/n−1/n/n+1), csv, docx 인용 수, 개정됨 판정. DB(`w13b-workspace.test.mjs`): 본인 RLS, 만료 정각 경계, 한도 n/n+1, 보존. E2E(`w13b-acceptance`): 모드 위조·비구독자·내보내기.

## 5. 남은 과제

- 메모·스크랩·폴더의 사용자당 개수 상한은 이번에 넣지 않았습니다(유료 권한이 있어야 만들 수 있어 남용 위험이 낮음, 코디네이터 결정 2026-10-27). 본문 20,000자·제목 200자 상한만 있습니다. 남용이 보이면 `settings`에 상한 키를 두는 방식으로 더합니다.
- 맞춤 브리핑 위젯은 W13-d의 `briefings` 표가 생긴 뒤 더합니다. 헤더 모드 토글은 부품(`ModeToggle`)만 만들었고 헤더에 끼우는 일은 리드가 합니다.
