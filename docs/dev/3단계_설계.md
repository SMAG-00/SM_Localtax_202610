# 3단계(W11) 심화·기관: 작업 단위 설계 (개발 문서)

PRD-03(v2.0, 요구사항 36개 — 2026-10-25 4-K FAM-10~15 추가)과 PRD_최종 §11.1 W11 행을 구현할 때 작업 단위·순서·마이그레이션 번호·데이터 이름을 맞추려고 정한 약속입니다. 이 문서와 PRD가 다르면 PRD를 따르고 이 문서를 고칩니다. 1·2단계 설계 문서의 값 목록·공개 읽기·캐시·기능 키·감사·승인 RPC 규칙은 그대로 따릅니다. (2026-10-25 작성)

**지키는 선 (2단계 설계와 같음, PO 결정 2026-10-25)**
- 실제 법령·세무 문장, 세율·공제·기한·한도 값, 감면·판정 요건, 달력 날짜를 쓰지 않습니다. AI는 구조와 시험 자료만 만듭니다(시험 자료는 `시험용` 표시 + 지어낸 값). 판정표·가이드·요건 사전·쟁점 지도·조례 요약·리포트 본문은 빈 칸으로 두고 감수 입력으로 채웁니다. SM 해설과 안심 계산기 룰셋 값은 "원본이 이미 가진 AI 작성·미감수 값"으로 보고 감수 서명 전에는 `draft`로만 둡니다.
- 새 기능은 모두 기능 키를 꺼 둔 채 출하합니다. 코드 완료와 공개 승인은 따로 둡니다.
- 결제는 시험(샌드박스) 모드만. 기관 계약은 계약서·세금계산서 기록으로만 엽니다.
- SM 부동산 세금 플랫폼과 「안심 상속증여계산기」 저장소는 읽고 복사만 합니다(두 폴더에 쓰기·설치·시험 실행·캐시 0, `.env`·`web/.env.local`·`web/.vercel/`은 열지도 복사하지도 않음).
- 국세 금액은 지금 PRD 원칙 ④와 CI `check-national-tax` 때문에 금지입니다. 상속·증여세 자체 계산(W11-g)은 **PO 결정: 포함(2026-10-25, 권고안)**이며, PRD 개정(4.4 첫 커밋 — 문서 개정 완료, 커밋 대기)과 CI 재설계(4.4 둘째 커밋)가 먼저 커밋되기 전에는 코드 한 줄도 넣지 않습니다. 양도세(양도소득세·지방소득세 양도소득분)는 개정 뒤에도 계속 금지입니다.
- 분야 이름: 지방세·부동산세금(`/tax`) / 부동산재테크(`/realestate`) / 부동산금융(`/finance`) / 지자체뉴스(`/local`). 사이트 이름은 `packages/ui/src/brand.ts`에서만 읽습니다.
