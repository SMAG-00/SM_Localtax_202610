# 「SM(선명) 지방세·부동산·지자체뉴스 종합 플랫폼」 PRD-05 5단계 — 확장

1~3단계에서 실제로 팔린 상품(지면 구독·도서·교육·디지털 구독·기관 구독)과 1단계 수익 대시보드(BIZ-09)의 상품별 공헌이익을 보고 유료 범위를 넓힌다. 30년 출판물을 권리 확인분부터 지식창고(월간지방세연구 e-Book·실무·편람 위키·프리미엄 칼럼)로 열고, 전문가 워크스페이스(고밀도 대시보드·분할 화면·쟁점 타임라인)와 리서치 코파일럿, 지방세 범위의 전문가 계산기, 인증 전문가 Q&A 라운지를 더한다. 준비되면 전문가 유료 등재(EXPL-11, P2 — 정액 광고 등재만)와 네이버 유료 연재·데이터 라이선스(BIZ-11, P2 — 제휴·계약 뒤)를 연다. 결제·요금제는 2단계 결제 기반(PRD-02 PAY·BIZ-04·05)을, 기관 좌석은 3단계(PRD-03 BIZ-07·PAY-04)를 넓혀 쓴다 — 새 결제·좌석 모듈을 만들지 않는다. 무료 영역(뉴스·금주 핫뉴스·기본 해설·개정 트래커·계산기 연결·기본 원문 검색·AI 도우미·전문가 소개)은 줄이지 않고, 방문자를 서둘러 결제로 밀지 않는다. 외부 전문가는 소개 대가 없는 광고형 디렉터리로만 소개하고, SM 소속 전문가 연락 요청은 1단계(PRD-01C)의 동의 기반 경로를 쓴다(PRD_최종 §2.2 원칙 ⑧). 국세 금액은 만들지 않는다(원칙 ④). 플랫폼 이름은 가칭이다.

## 1. 목표와 범위

### 1.1 목표

- 교육·출판·구독·기관 상품으로 한국지방세연구회(주)의 지속 가능한 수익성을 높인다. 1~3단계에서 실제로 팔린 상품의 매출·갱신과 상품별 공헌이익(유료 매출 − 직접/변동 비용)을 1단계 수익 대시보드(BIZ-09, PRD-01C)로 보며 넓힌다.
- 무료 영역(뉴스·금주 핫뉴스·기본 해설·개정 트래커·계산기 연결·기본 원문 검색·AI 도우미·전문가 소개)은 무상으로 열어 두고, 실무 서적 열람·AI 한도·전문가 계산기를 유료로 한다 (RP-18 · RP-19, PRD_최종 §8). 방문자를 서둘러 결제로 밀지 않는다.
- 전문가가 법령·판례·해석·실무서를 한 화면에서 대조한다. 전문가 모드는 고밀도 대시보드·분할 화면·쟁점 타임라인으로 바뀌고, 메모·저장 검색·내보내기·알림으로 실무에서 떠나지 않게 한다 (삼일아이닷컴 락인, BM-A1).
- 30년 출판 자산을 권리를 확인한 분량부터 지식창고로 공개한다.
- 인증 전문가가 답하는 지방세 고민 해결 라운지를 연다. 라운지는 질문·답변까지이고 소개 대가·건별 수수료·수임 관여가 없다. 개별 상담이 필요한 이용자는 1단계 전문가 소개·SM 전문가 연락 요청(PRD-01C EXPL)으로 잇는다. 플랫폼 중립성을 화면에 밝힌다 (원칙 ⑧).
- 주간 브리프의 프리미엄판과 제휴 피드로 미디어 수익을 넓힌다 (택스워치 모델).
- 기관 라이선스를 팔기 전에 정보보호 인증의 종류·범위·위험평가·일정 계획을 승인한다 (SEC-02). 인증 취득 자체는 이 단계의 완료 조건이 아니다.
- 준비되면 전문가 유료 등재(정액 광고 등재만, EXPL-11)와 네이버 유료 연재·데이터 라이선스(BIZ-11)를 연다 — 둘 다 P2이며 법률 검토·제휴 계약이 끝난 뒤에만 연다.
- 국세 금액은 만들지 않는다. 전문가 계산기도 지방세 범위로만 계산하고 국세가 들어간 비교는 SM 부동산 세금 플랫폼으로 연결한다 (원칙 ④).

## 2. 사용자 여정

**J3 — 심판청구 유사 사례 비교 (U4)** — 코파일럿 단계는 4단계 지방세봇 공개 단계를 따른다 (1.3).

1. 전문가 모드로 로그인하면 워크스페이스 대시보드가 열린다. "저장 검색 새 결과" 위젯에 지난주 저장한 "과점주주 · 간주취득 · 인용" 조건의 새 결정례 2건이 보인다.
2. 결정례 DB를 같은 조건으로 거르고 다섯 건을 고른 뒤 리서치 코파일럿의 [비교표 만들기]를 누른다. 쟁점·사실관계·결론·근거 조문 표가 "AI 초안" 표기와 함께 나온다.
3. 표를 폴더에 메모로 저장하고, 관련 조문을 3단 보기로 연다. 오른쪽 관련 자료 패널 v2가 같은 쟁점의 위키 해설과 프리미엄 칼럼을 "추천 이유"와 함께 보여 준다.
4. 비교표를 .docx로 내보낸다. 인용마다 사건번호·결정일·확인일이 붙어 있어 이유서 초안에 그대로 옮긴다.

### 3.3 화면 규칙

- 일반 모드 화면(요금 안내·결제·라운지·프리미엄 칼럼 미리보기·페이월·홈 해결 사례·관심 지역 알림 켜기)은 PRD-00 8.2 R1~R11을 모두 지킨다.
- 전문가 모드 화면(대시보드·분할 화면·쟁점 타임라인·3단 보기·코파일럿·전문가 계산기·계정과목 연결)는 PRD-00 8.7을 따른다. R1~R3·R7·R10은 빼고 R4~R6·R8·R9·R11은 지킨다.
- **결제로 서둘러 밀지 않는다** (PRD_최종 §8). 무상 범위 화면(분야 허브·기사·금주 핫뉴스·지자체 허브·개정 트래커·기본 해설·계산기 연결·기본 원문 검색·AI 도우미·전문가 소개)에 페이월·구독 모달·전면 배너·결제로 가는 주 버튼 0. 프리미엄 안내는 잠금 배지가 붙은 자료(관련 자료 패널 카드·인용 칩)와 페이월, `/store/subscription`, `구독·도서` 영역에서만 보인다. 보도기사 본문 사이에 상품 배너를 넣지 않는다 (NAV-06 · 기사 하단 자사 상품 카드는 1개 이하, BIZ-03). E2E가 무상 범위 화면마다 페이월·모달 컴포넌트 수 0을 확인한다.
- 컴포넌트는 PRD-00 8.6의 5단계 컴포넌트(모드 토글·대시보드·분할 화면·쟁점 타임라인·활동 전문가 띠·페이월)와 기존 인용 칩·결정례 카드·잠금 배지·관련 자료 패널·데이터 차트·폼 요소를 그대로 쓴다. 새 색·그림자·그라데이션을 만들지 않는다.
- 프리미엄 자료는 인용 칩 끝의 자물쇠와 잠금 배지(`bg-navy-900 text-hermes-300`)로 표시한다. 색만으로 잠금을 전하지 않는다.
- 금지 표현(PRD-00 8.8 — "명품", "무료 상담", "최저가", "절세 보장" 등)은 요금 안내·프리미엄 칼럼·라운지·전문가 프로필·알림 메일 문구에도 검사한다. 광고는 "광고", 제휴 콘텐츠는 "공동 기획"으로 표시하고 섞지 않는다.
- 상품 페이지는 `자사 상품` 표기(PRD-01C BIZ-03)와 상품 콘텐츠 유형으로 표시하고 기사 목록·뉴스 전송 후보와 섞지 않는다 (NAV-02). 전문가 유료 등재 카드는 `광고`로 표시한다.
- 분할 화면 경계는 키보드(← →)로도 조절하고, 쟁점 타임라인은 목록 구조로 마크업해 스크린 리더가 시간순으로 읽게 한다 (PRD-00 8.9).
- 1024px 미만에서는 분할 화면을 탭으로, 대시보드 위젯을 1열로 바꾼다. 전문가 모드 다크 모드는 P2다 (PRD-00 8.7).

### 4.5 구독·결제 (요구사항 없음 — 2·3단계로 옮김)

v2.1이 결제를 2단계(BIZ-04·05), 기관 구독을 3단계(BIZ-07)로 당겨, v1.2의 PAY-01·02·03·05·06·07은 PRD-02 4.15 결제 기반으로, PAY-04(기관 좌석·세금계산서)는 PRD-03 4-E로 옮겼다 (ID·우선·근거 그대로). 이 단계는 그 결제·권한 구조에 지식창고·워크스페이스·코파일럿 권한 항목을 더한다 — 새 결제·좌석 모듈을 만들지 않는다. 더하는 권한의 시험은 LIB-04(페이월)·WS-02(권한 없는 회원의 둘러보기)·RES-05(프리미엄 전용 한도)·SEC-02(기관 라이선스 게이트)의 수용 기준과 8장 결제·좌석 회귀로 한다. 넓히는 작업은 수요·법률·결제 게이트를 통과한 뒤에 한다 (1.3).

맞춤 AI 브리핑(WS-06)과 관련 자료 패널 v2의 추천(LAW-10)은 에이전트가 아니다. 승인된 콘텐츠를 규칙·기존 색인 벡터의 유사도로 고르는 배치·조회이며 새 문장을 만들지 않는다. 그래서 검수 큐를 거치지 않고, 대신 "공개 상태 콘텐츠만 쓴다"를 테스트로 강제한다. 5단계 상품의 매출·비용은 1단계 수익 대시보드(BIZ-09)의 원장에 더하며 AI를 부르지 않는다 (PRD_최종 v1.7 §7.1).

## 9. 구현 작업 순서

PRD_최종 §11.1의 W13에 해당한다. 각 작업은 `설계/마이그레이션 → 최소 기능 → 실패 경계 테스트 → E2E → 편집/감수 확인 → 배포`로 닫는다. 권리·감수·법률이 필요한 작업은 코드 완료와 공개 승인을 따로 기록한다. `[게이트 후]` 표시 작업은 수요·법률·결제 게이트를 통과해야 착수한다. 주차는 단계 착수 기준의 참고 순서이며 총기간은 W0 실사 뒤 다시 산정한다.

## 13. 이후 과제 (2년차)

- 모바일 앱, 카카오톡 채널 상담봇.
- 기관 전용(설치형) 지방세봇 — 지자체 내부 자료를 근거로 쓰는 버전.
- 지자체 내부 시스템 연동, 영상 콘텐츠 자동화.
- 정보보호 인증 획득과 갱신 — 이 단계의 추진 계획(SEC-02)을 이어 심사를 받고, 인증 범위를 기관 전용 지방세봇까지 넓힌다.
- 계정과목 연결 확대 — 회계기준 연계는 권리를 확인한 뒤 참조 범위를 넓힌다. 법인세 세무조정 연계는 범위 밖으로 둔다.
- 제휴 피드의 유상 API 전환, 네이버 외 유료 채널 검토 (결정 안건 결과에 따라).
- 전문가 유료 등재(EXPL-11)를 이 단계에 열지 않았으면 다시 검토한다 — 정액 광고 등재만, 무료 목록·활동 띠와 분리된 자리로.
- 전문가 모드 다크 모드 — 이 단계에 하지 못하면 이어서 한다.
- 상품별 공헌이익의 기준선이 쌓이면 상품 목표 수치를 정하고, 공헌이익이 낮은 상품의 개선·중단을 검토한다.
