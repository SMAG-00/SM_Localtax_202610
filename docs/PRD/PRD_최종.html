SM(선명) 플랫폼은 월간지방세연구(localtaxresearch.com)를 지방세 중심의 4대 분야 전문 매체로 다시 짓고, 그 신뢰를 구독·도서·교육·상담 매출로 바꿉니다. 이 정리본은 상세본 SM 지방세·부동산·지자체뉴스 종합 플랫폼 PRD v2.0의 16개 장과 신규 요구 147개를 하나의 흐름으로 다시 묶은 것입니다. 요구별 상세 수용 기준은 상세본의 같은 ID를 따릅니다.

1장

v2.0 분석 결과와 정리 방식

v2.0은 요구는 충실하지만 세 번의 추가 지시(AI 도우미, 전문가 소개, SM 전문가 연락)를 뒤에 덧붙이면서 구조가 흐트러졌습니다. 정리본은 내용을 빼지 않고 순서·중복·충돌을 바로잡았습니다.

# v2.0에서 발견한 문제 정리본의 조치
1 AI 도우미(15장)·전문가 소개(16장)가 수용 테스트·참고 자료(14장) 뒤에 붙어 있음 6장 ‘공통 서비스’로 옮기고 참고 자료는 맨 끝(14장)에 둠
2 인프라 계정·.env 관리(12.2)가 법률 장 안에 섞여 있음 9장 ‘기술·인프라’로 옮기고 법률은 10장에 따로 모음
3 데이터 모델이 11장·15.4·16장 세 곳에 흩어짐 9.3 통합 데이터 모델 한 표로 합침
4 [결정]·[실사]·[감수] 표시가 30곳 넘게 흩어짐 13장 한 표로 모아 담당·시점을 붙임
5 성공 지표에 AI 도우미·전문가 연락 요청 지표가 없음 3.3 지표표에 추가
6 수익표의 ‘SM 소속 전문가 상담’·‘전문가 유료 등재’가 수익 요구(BIZ)와 연결되지 않음 8장에서 상품·조건·ID를 한 표로 연결(전문가 유료 등재는 2026-10-24 폐기)
7 원칙 “전문가 수임 중개는 범위 밖”과 SM 전문가 연락 요청이 충돌해 보임 원칙 8로 한 번에 정의: 전문가 소개는 SM(선명) 소속 전문가만(2026-10-24 PO 결정 — 외부 전문가 소개는 하지 않음), SM 소속 전문가는 이용자 동의 기반 연락 요청
8 로드맵 그림 1단계에 전문가 소개가 빠짐 11장 로드맵에 반영
9 제품명 ‘SM’의 의미가 문서마다 달리 쓰임(SM 플랫폼·SM 소속) ‘SM(선명)’ = 브랜드·운영 주체, ‘SM 부동산 세금 플랫폼’ = 기존 계산기 사이트로 구분
10 같은 규칙(입력값 비전달, 광고 분리, 고지문 등)이 여러 ID에 반복 2장 불변 원칙으로 올리고, 각 장은 기능 묶음 표로 요약

읽는 법: 2장 원칙과 13장 결정 사항을 먼저 보고, 구현은 5~9장의 기능 묶음 → 11장 작업 단위 순서로 봅니다. 개별 요구의 세부 기준이 필요하면 상세본에서 같은 ID를 찾습니다.

2.2 불변 원칙

  1. 세액은 감수된 결정론적 엔진만 냅니다. AI는 세액·감면 판정·개별 세무 결론을 만들지 않습니다.
  2. AI와 자동화는 안내·초안에만 쓰고, 대외 발행은 사람이 승인합니다.
  3. 계산 입력값은 서버·이벤트·URL에 저장하거나 보내지 않습니다.
  4. 국세(상속세·증여세·양도세) 금액은 만들지 않고 외부 계산기·국세청으로 연결합니다.
  5. 기존 SM 부동산 세금 플랫폼은 바꾸지 않습니다. 1단계는 연결, 2단계는 검수된 엔진을 복사합니다.
  6. 기사·정보 목록(행사·분양)·계산 도구·광고·상품을 CMS·URL·화면·구조화 데이터에서 구분합니다.
  7. 투자 추천, 시세·금리 예측, 세무 신고 대행은 하지 않습니다.
  8. 전문가 소개는 SM(선명) 소속 전문가만 합니다 — 프로필은 관리자가 등록하고(AI가 쓰지 않음), 외부 전문가 등재·유료 등재·소개 대가는 없습니다(2026-10-24 PO 결정). SM 소속 전문가는 이용자가 동의해 남긴 질문 요약을 받아 연락하는 경우에만 정보를 전달합니다.
  9. 출처·기준일·권리가 확인된 자료만 공개하고, 증빙 없는 경력·숫자는 표시하지 않습니다.
  10. Vercel·Supabase 클라우드로 시작해 사내 Docker로 옮길 수 있게 만들고, 개발 포트는 localhost:3001로 고정합니다.

4.3 핵심 여정

  1. 지방세 공무원: 홈 → 개정 트래커(2026년 지방세제 개편안) → 개정 브리핑 → 원문 → 교육원 개정세법 강좌 신청.
  2. 조합원: “○○구역 관리처분 취득세” 검색 → 프로젝트 페이지 → 재개발 상세 → 「지방세로 읽기」 → SM 취득세 계산기(새 창).
  3. 개발금융 실무자: PF 책임준공 사례 → 신탁 구조 해설 → 칼럼 → 브리핑 구독 → (3단계) 기관 구독.
  4. 지역 주민: 우리 구 금주 핫뉴스 → 정비계획 주민설명회 → 프로젝트 트래커 → 관심 프로젝트 알림.
  5. 개별 상담이 필요한 이용자: AI 도우미에 “제 경우 감면되나요?” → 관련 해설 + ‘SM 전문가 보기’ 또는 ‘SM 전문가에게 연락 받기’ → 요약 확인·동의 후 제출 → 담당 전문가 연락.
  6. AI 검색 유입: AI 모드 답변의 인용 링크 → 「지방세 50문 50답」 → 관련 도서 카드 → 스토어.

요청 도우미의 동작 전문가 연결

트래커·프로젝트·행사 상태 DB 조회 결과를 그대로 —
구독·도서·교육, 정정·제보 안내 페이지·접수 양식으로 —
하지 않음 — 세액 계산 금액을 만들지 않고 SM 계산기로 지방세 전문 세무사
하지 않음 — 상속세·증여세 외부 계산기·국세청 안내로 상속·증여 세무 전문가
하지 않음 — 감면 등 개별 판단 판단 없이 관련 해설·원문 해당 세목 세무사
하지 않음 — 조합·신탁 법률 분쟁 판단 없이 해설·사례 정비·신탁 전문 변호사
하지 않음 — 분양·투자 추천, 시세 전망 추천·전망 없음 감정평가사·변호사(투자자문 소개 없음)

6.4 SM(선명) 소속 전문가 연락 요청(EXPL-13~21)

이용자가 궁금한 점을 요약해 남기면 SM 소속 전문가가 먼저 연락합니다. 이 경로에서만 이용자가 확인·동의한 요약과 연락처를 전달하고, 상담·업무는 자격 있는 수행 주체(세무사 사무소·세무법인·법률사무소 등) 명의로 이뤄집니다.

  1. 진입 — 도우미의 ‘하지 않음’ 응답, /experts 상단, 기사·칼럼 하단.
  2. 요약 — 도우미에서 오면 마스킹된 대화로 AI 초안을 양식에 채우고, 직접 오면 이용자가 씁니다.
  3. 확인·동의 — 이용자가 요약을 고치고 분야·연락처·희망 시간을 넣은 뒤 필수 동의 후 직접 제출합니다. 연락처는 Claude API로 보내지 않습니다.
  4. 배정 — 분야별 당번표로 배정하고, 담당자에게는 개인정보 없는 보안 화면 링크만 알립니다.
  5. 연락 — 목표 시간(예: 1영업일) 안에 연락해 업무 범위·비용·수행 주체를 먼저 안내합니다.
  6. 종결 — 계약은 이용자와 전문가(사무소)가 직접 맺고, 플랫폼은 상태만 기록한 뒤 보관 기간(기본 1년)이 지나면 파기합니다.

접수와 첫 연락은 무료이며, 요청 데이터는 담당자·운영 책임자만 열람(RLS·감사 로그)하고 기사·AI 학습·마케팅에 쓰지 않습니다. 주민등록번호·계좌번호 입력은 막고, 기한이 임박한 사안은 직접 연락을 권합니다.
