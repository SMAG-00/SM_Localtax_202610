## 남은 조치

1. **세 서비스 모두 2단계 인증을 켜고 위 표에 적는다.** PO가 화면에서 확인한다.
2. **관리자 2명 이상을 둔다.**
   - 회사 계정을 하나 더 정해 각 서비스에 관리자로 초대한다.
   - GitHub은 개인 계정에 관리자를 둘 수 없다. 조직(Organization)을 만들고 저장소를 그리로 옮긴다. 저장소 이전은 몇 분이면 된다.
3. **유료 전환 시점:** 실제 공개 전에 아래 셋이 유료 요금제가 필요하다(docs/03 2-2).
   - Vercel Pro: 상업용 운영
   - GitHub Team 또는 Pro: main 보호 규칙, 비공개 저장소의 비밀값 push 차단
   - Supabase Pro: 운영 DB 백업·중지 방지
4. Anthropic·Resend 계정은 그 기능을 만들기 직전에 연다.
